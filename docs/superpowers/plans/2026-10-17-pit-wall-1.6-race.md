# Pit Wall 1.6 Plan A (race) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the race half of Pit Wall 1.6. The AI stops churning tyres in showers and never boxes on the final boundary. A new player's first career race is fully dry. Pit stops can go slow. The driver asks the strategist yes/no questions on the radio. The weather strip gives an honest, imprecise forecast. A crash can bring out a red flag, with a free tyre change and a standing restart. Determinism, the golden race, every existing Monte-Carlo band and every save are preserved.

**Architecture:** Every mechanic lands in the pure engine first (`src/engine/`, seeded, numbers in `tuning.json`). A new roll either reuses a value that is already drawn (the slow stop reuses the discarded `g2` of `pitStopTime`'s `gaussianPair`) or short-circuits with no draw at a zero rate (the red flag). Every new behaviour has a tuning value that reproduces the old stream exactly, and `makeDeterministicTuning` pins that value, so `tests/engine/byteIdentity.test.ts` passes against its untouched fixture. Pure detectors live in `state/` (radio requests) or `engine/` (forecast, red-flag restart), and the UI only reads them. The red flag reuses the existing start lights through a new race phase, `'red_flag'`. The player's restart tyre is a logged `PlayerCall`, so replay and the debrief reproduce it.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess`), React 19 + framer-motion, Zustand 5, zod 4, Vitest 4 (jsdom), PixiJS 8, Capacitor 8.

**Spec:** `docs/superpowers/specs/2026-10-17-pit-wall-1.6-design.md`. Plan A covers §0–§4 and the Global constraints. The spec is binding. Also read `CLAUDE.md` and `MODEL_SPEC.md` §3, §10 and §14.

## Global Constraints

- The engine stays pure and deterministic: same seed + same inputs ⇒ identical race. New rng draws only on paths that short-circuit with **no draw** when their rate is 0. `tests/engine/byteIdentity.test.ts` and its golden fixture pass unchanged and are never re-captured. New `RaceState` fields are absent (not `undefined`) on the default path.
- Every balance number lives in `src/data/tuning.json` with zod validation.
- Monte-Carlo regression bands: every existing band holds unless the spec names it as moving. Moved or new bands are measured (4 cells × n=240, the Task 2 sizing rule) and written into `tuning.json._regressionBands` and `MODEL_SPEC.md`.
- Saves: season `SAVE_VERSION` 2, career 1, cloud 1. No bumps. New persisted fields are additive with zod `.optional()`/`.default()`, appended last and in the same order in schema and snapshot. The real 1.4 fixtures keep loading. (Plan A adds no persisted field.)
- Settings keys: appended to `settingsStore` `K` and to the positional destructure in `loadSettings` in the same order. (Plan A adds no setting.)
- Race Day Bold tokens only. Volt = player / call to action. Caution = race control. Hot = urgent. Text on volt, caution or hot fills is ink. Tabular figures on live numbers. Reduced motion respected. Every new control is ≥ 44px with a screen-reader label. Colour is never the only signal.
- No re-render storms: narrow Zustand subscriptions. No per-frame allocations in Pixi.
- Never two full `vitest run`s at once. Bounded loops in tests (a `MAX_STEPS` bound plus a terminal assertion).
- Scenarios depend on byte-identical engine behaviour. If a change moves a scenario's handover, re-author it with `scripts/find-scenarios.ts` (first hit meeting its brief, goal = par − 1, blurb kept true).
- Start values (all tunable, all flagged for Veet as **Call**s in the spec):
  - `ai.weatherConfirmLaps` 2, `ai.weatherMinLapsLeft` 3.
  - `pit.slowStopChance` 0.04, `pit.slowStopMin` 2.0, `pit.slowStopMax` 6.0, `pit.pitCrewSlowRelief` 0.5.
  - `radioRequests`: boxCliffFrac 0.85, pushGap 1.0, cooldownLaps 6, maxPerRace 3, expirySec 8.
  - `weather.forecastHorizon` 10, `forecastSpread` `[0,1,1,2,2,3,3,3,4,4,4]`, `forecastConfidence` `[1,1,.9,.85,.8,.75,.7,.65,.6,.55,.5]`.
  - `incidents.redFlag`: crashChance 0.05, maxPerRace 1, minLapsLeft 5, planWindowLaps 15.

## Review Focus

1. **A red flag shown on the lap-completing tick (sector 2).** The restart must NOT happen on that same boundary. The SC/VSC lap countdown must not end it. The AI must not box on that boundary. The restart comes on the next lap's boundary. Test owned by Task 9 (`A RED FLAG ON THE LAP-COMPLETING TICK`).
2. **A `restart_tyre` call that does not land on a pending red flag.** This happens in debrief futures, where the red flag falls elsewhere or never comes. The call must be a no-op that never throws, and the AI rule picks the tyre. A real red-flag race must replay byte-identically from its call log. Tests owned by Task 10 (`A STALE RESTART CALL IS A NO-OP`, `REPLAY REPRODUCES A RED-FLAG RACE`).
3. **A red flag arriving while the pit panel is open, a box request is pending, or the player is out.** The panel closes and the request is dropped. A retired player gets no card, and the race carries on under the AI rule. Test owned by Task 11 (`RED FLAG WITH THE PIT PANEL OPEN AND A REQUEST PENDING`, `A RETIRED PLAYER GETS NO CARD`).
4. **A radio request that goes stale before it is answered.** A plan stop lands, the player pits with the button, or the player sets PUSH by hand. The request must be withdrawn so YES can never charge a second stop. A paused clock freezes the expiry. Tests owned by Task 6 (`A STALE BOX REQUEST CANNOT CHARGE A SECOND STOP`, `THE EXPIRY FREEZES WHILE PAUSED`).
5. **The forecast near the flag.** A change past the last lap, a state on the final lap, or a finished state reads "steady". The window is clamped to `[1, laps left]` and always contains the true lap. There is never a NaN chance. Test owned by Task 7 (`NEAR THE FLAG`).

> **Ruling recorded for Veet (R1): the final-lap guard keeps the pace mode.** The spec says aiDecision "is not run" on the boundary that completes the race. This plan instead still runs it on that boundary, applies the pace mode it returns, and drops its pit request (no `pitStopTime` call, no stop).
>
> The reason is the golden fixture. It records the final state, and on that boundary 14 of 20 AI cars switch neutral → push. Not running aiDecision would change the fixture, which the Global constraints forbid re-capturing.
>
> Racing outcome is identical either way, because no sector follows the final boundary.

> **Ruling recorded for Veet (R2): which laps count as "the past".** At a lap boundary the AI's state has `lap` = the lap about to start. Its `weatherState` is still the weather of the lap just completed (`stepSector` advances it after the AI decides). The consecutive-lap count therefore starts at `weatherState` (the lap just completed) and walks back through `weatherTimeline[lap-2], [lap-3], …`. It never reads index ≥ `lap`.
>
> With `weatherConfirmLaps` = 1 and `weatherMinLapsLeft` = 0 this is exactly the old rule. `makeDeterministicTuning` pins those two values so the golden race stays byte-identical. Most engine unit tests therefore run the old weather AI, unless they set the shipped values as the tests below do.

```ts
/**
 * The AI's view at the boundary that starts lap `lap`: `weatherState` is the
 * lap just completed (lap - 1); `past` fills timeline[lap-1-past.length ..
 * lap-2]; `future` fills timeline[lap ..] and must never matter.
 */
function view(c: CarState, lap: number, justCompleted: WeatherState, past: WeatherState[], future: WeatherState = 'DRY'): RaceState {
  const tl: WeatherState[] = Array(30).fill('DRY')
  past.forEach((w, i) => { tl[lap - 1 - past.length + i] = w })
  tl[lap - 1] = justCompleted
  for (let i = lap; i < 30; i++) tl[i] = future
  return {
    lap, sector: 0, totalLaps: 30, cars: [c], sectorResults: [], overtakeEvents: [],
    safetyCar: null, incidents: [], trackEvolutionLaps: lap, rngState: 1,
    weatherTimeline: tl, weatherState: justCompleted,
  }
}

const decide = (tuning: TuningConstants, c: CarState, s: RaceState) => aiDecision(makeConfig(tuning), c, s, createRng(1))

describe('confirmed weather stops (spec 1.6 §0.1)', () => {
  const T = tuningWith(SHIPPED_AI)

  it('ONE DAMP LAP DOES NOT BOX A CAR ON SLICKS', () => {
    expect(decide(T, car('H', 10), view(car('H', 10), 10, 'DAMP', ['DRY'])).pit).toBe(false)
  })

  it('two consecutive non-dry laps do: inters on a damp track, wets on a wet one', () => {
    expect(decide(T, car('H', 10), view(car('H', 10), 10, 'DAMP', ['DAMP']))).toEqual({ pit: true, compound: 'I', paceMode: 'neutral' })
    expect(decide(T, car('H', 10), view(car('H', 10), 10, 'DAMP', ['WET']))).toEqual({ pit: true, compound: 'I', paceMode: 'neutral' })
  })

  it('a WET track boxes a car on slicks at once, unconfirmed', () => {
    expect(decide(T, car('H', 10), view(car('H', 10), 10, 'WET', ['DRY']))).toEqual({ pit: true, compound: 'W', paceMode: 'neutral' })
  })

  it('a wet-tyred car waits for two dry laps before fitting slicks', () => {
    expect(decide(T, car('I', 10), view(car('I', 10), 10, 'DRY', ['DAMP'])).pit).toBe(false)
    expect(decide(T, car('I', 10), view(car('I', 10), 10, 'DRY', ['DRY']))).toEqual({ pit: true, compound: 'M', paceMode: 'neutral' })
  })

  it('NEVER READS THE FUTURE: a soaking forecast does not confirm a single damp lap', () => {
    expect(decide(T, car('H', 10), view(car('H', 10), 10, 'DAMP', ['DRY'], 'WET')).pit).toBe(false)
  })

  it('no weather stop with weatherMinLapsLeft or fewer laps to go', () => {

  })

  })

  it('counts back no further than lap 0 (the first boundary of the race)', () => {
    expect(decide(T, car('H', 1), view(car('H', 1), 1, 'DAMP', [])).pit).toBe(false)
```

In `src/engine/strategy.ts` replace lines 33-40 (`function weatherPit`) with:

```ts
/**
 * How many consecutive COMPLETED laps, ending with the one just completed,
 * satisfy `pred`. At a lap boundary `state.weatherState` is still the lap just
 * completed (stepSector advances it after the AI decides), so it counts first
 * and the walk continues through timeline[lap-2], [lap-3], ... It never reads
 * index >= state.lap: the AI does not see the future (spec 1.6 §0.1, ruling R2).
 */
function weatherRun(state: RaceState, pred: (w: WeatherState) => boolean): number {
  if (!pred(state.weatherState)) return 0
  let n = 1
  for (let i = state.lap - 2; i >= 0; i--) {
    const w = state.weatherTimeline[i]
    if (w === undefined || !pred(w)) break
    n++
  }
  return n
}

/**
 * Tyre-family changes for the weather, all brains. Before 1.6 this boxed every
 * AI car the lap the track turned DAMP and again the lap it turned DRY, ~100
 * stops a race on a showery circuit. Now a change must hold for
 * ai.weatherConfirmLaps completed laps (a WET track boxes slick-shod cars at
 * once), and there is no weather stop with ai.weatherMinLapsLeft laps or fewer
 * to go. The AI will sit out short damp spells on slicks and lose time: that
 * is the intended trade. Pure threshold, no rng.
 */
function weatherPit(car: CarState, state: RaceState, config: RaceConfig): AIDecision | null {
  const compSpec = config.compounds[car.compound]
  if (!compSpec) return null
  const ai = config.tuning.ai
  if (state.totalLaps - state.lap <= ai.weatherMinLapsLeft) return null
  const now = state.weatherState
  if (compSpec.type === 'dry' && now !== 'DRY' &&
      (now === 'WET' || weatherRun(state, w => w !== 'DRY') >= ai.weatherConfirmLaps)) {
    return { pit: true, compound: now === 'WET' ? 'W' : 'I', paceMode: 'neutral' }
  }
  if (compSpec.type === 'wet' && now === 'DRY' && weatherRun(state, w => w === 'DRY') >= ai.weatherConfirmLaps) {
    return { pit: true, compound: 'M', paceMode: 'neutral' }
  }
  return null
}
```

- Consumes: `gaussianPair` (rng.ts), `effectivePitLaneLoss` (incidents.ts).
- Produces:
  - `export interface PitStopCost { total: number; slow: number }` (pitStop.ts).

  - `Metrics.slowStopsPerRace`, and the band `slowStopsPerRace`.

> **Ruling recorded for Veet (R4): which slow stops are logged and announced.** The engine logs `slow_stop` for EVERY slow stop, whoever made it. The commentary announces a rival's slow stop only when it "costs a position". That is tested on the post-stop state: with the slow seconds removed, the car would be ahead of the car now directly in front of it (`raceTime − timeLoss < ahead.raceTime`). The player's own slow stop goes to the radio (Task 4), not the commentary.

Replace `src/engine/pitStop.ts` with:

```ts
import type { RaceConfig, RaceState } from './types'
import { gaussianPair, type Rng } from './rng'
import { effectivePitLaneLoss } from './incidents'

/** What one stop cost. `slow` is the part of `total` that was a slow stop (0 if it was not). */
export interface PitStopCost { total: number; slow: number }

/**
 * Standard normal CDF, Abramowitz & Stegun 7.1.26 (|error| < 1.5e-7). Plain
 * arithmetic, so it is as deterministic as the rest of the engine.
 */
export function normalCdf(x: number): number {
  const t = 1 / (1 + 0.3275911 * Math.abs(x) / Math.SQRT2)
  const poly = (((((1.061405429 * t - 1.453152027) * t) + 1.421413741) * t - 0.284496736) * t + 0.254829592) * t
  const erf = 1 - poly * Math.exp(-(x * x) / 2)
  return x >= 0 ? 0.5 * (1 + erf) : 0.5 * (1 - erf)
}

/** Lane loss plus the team's effective mean stationary time. No rng: the expected stop. */
export function expectedPitStopTime(config: RaceConfig, teamId: string, safetyCar: RaceState['safetyCar']): number {
  const team = config.teams.find(t => t.id === teamId)!
  const crewFactor = team.facets.pitCrew / 100
  // Under yellow the lane loss is the neutralisation's, not the circuit value.
  return effectivePitLaneLoss(config.circuit, safetyCar, config.tuning) +
    (config.tuning.pit.stopMean - crewFactor * config.tuning.pit.pitCrewMeanRelief)
}

/**
 * The slow-stop seconds for a standard normal sample `g` (spec 2026-10-17 §1).
 * Slow when Φ(g) > 1 - p, i.e. g > Φ⁻¹(1 - p); the depth into that tail sets
 * where in [slowStopMin, slowStopMax] it lands. p = 0 returns 0 without even
 * evaluating Φ.
 */
export function slowStopComponent(config: RaceConfig, teamId: string, g: number): number {
  const pit = config.tuning.pit
  if (pit.slowStopChance <= 0) return 0
  const crew = config.teams.find(t => t.id === teamId)!.facets.pitCrew / 100
  const p = pit.slowStopChance * (1 - crew * pit.pitCrewSlowRelief)
  if (p <= 0) return 0
  const u = normalCdf(g)
  if (u <= 1 - p) return 0
  const frac = Math.min(1, (u - (1 - p)) / p)
  return pit.slowStopMin + (pit.slowStopMax - pit.slowStopMin) * frac
}

/**
 * The time one pit stop costs, for ANY stop: an AI decision, the player's
 * plan, or the player's PIT button. One model, so a player's pit crew counts
 * however the stop is called. Draws exactly one gaussianPair from `rng`: the
 * first value is the stationary-time noise, the second decides a slow stop --
 * no extra draw, so the stream is the same with slow stops on or off.
 * `allowSlow: false` prices the expected stop (the projection).
 */
export function pitStopTime(
  config: RaceConfig, teamId: string, safetyCar: RaceState['safetyCar'], rng: Rng,
  opts: { allowSlow?: boolean } = {},
): PitStopCost {
  const [stopNoise, g2] = gaussianPair(rng)
  const team = config.teams.find(t => t.id === teamId)!
  const crewFactor = team.facets.pitCrew / 100
  const effectiveStopSigma = config.tuning.pit.stopSigma * (1 - crewFactor * config.tuning.pit.pitCrewSigmaRelief)
  // Same association as the pre-1.6 expression ((lane + mean) + noise x sigma),
  // so a zero slow chance is byte-identical to it.
  const base = expectedPitStopTime(config, teamId, safetyCar) + stopNoise * effectiveStopSigma
  const slow = opts.allowSlow === false ? 0 : slowStopComponent(config, teamId, g2)
  return { total: base + slow, slow }
}
```

```ts
import type { RaceConfig, RaceState, Compound } from '@engine/types'
import { tyreCliffFraction, effectiveTyreAge } from '@engine/tyres'
import { bestDryCompound } from '@engine/strategy'
import { neutralisationKind } from '@engine/incidents'

/**
 * Driver radio requests (spec 2026-10-17 §2): the driver occasionally asks a
 * yes/no question. Detection is a pure function of the race state plus a small
 * tracker the caller threads through (like radioMapper's RadioState), so it is
 * deterministic and unit-testable. Picking the words and the countdown live in
 * raceStore / RadioRequest.tsx. Checked at lap ends only (ruling R6).
 */
export type RadioRequestKind = 'box' | 'push'

export interface RadioRequest {
  kind: RadioRequestKind
  /** state.lap at the lap end that raised it. */
  lap: number
  /** The car the player wants to attack (push only). */
  aheadId: string | null
  /** What YES fits (box only). */
  compound: Compound | null
}

export interface RequestTracker {
  asked: number
  lastAskedLap: Record<RadioRequestKind, number>
  /** pitsDone when the last box request was made: one per stint. -1 = never. */
  boxAskedAtPits: number
  /** Consecutive lap ends within pushGap of the same car ahead. */
  closeLapEnds: number
  closeAheadId: string | null
  lastLapSeen: number
}

export function makeRequestTracker(): RequestTracker {
  return {
    asked: 0,
    lastAskedLap: { box: Number.NEGATIVE_INFINITY, push: Number.NEGATIVE_INFINITY },
    boxAskedAtPits: -1,
    closeLapEnds: 0,
    closeAheadId: null,
    lastLapSeen: -1,
  }
}

export interface RequestContext {
  /** The player's car is still in the pit lane. */
  inPit: boolean
  /** A box request is suppressed while the pit panel is open (spec §2). */
  pitPanelOpen: boolean
  /** A request is already on screen: never stack them. */
  pending: boolean
}

/** The last completed lap's time: the car's three most recent sector results. */
function lastLapTime(state: RaceState, driverId: string): number | null {
  let sum = 0
  let n = 0
  for (let i = state.sectorResults.length - 1; i >= 0 && n < 3; i--) {
    const r = state.sectorResults[i]!
    if (r.driverId !== driverId) continue
    sum += r.sectorTime
    n++
  }
  return n === 3 ? sum : null
}

/** What YES to a box request fits (ruling R6): the weather family on a non-dry track, else the next planned stop, else the AI's best dry compound. */
export function boxRequestCompound(config: RaceConfig, state: RaceState): Compound {
  if (state.weatherState === 'WET') return 'W'
  if (state.weatherState === 'DAMP') return 'I'
  const player = state.cars.find(c => c.isPlayer)
  const next = player && config.playerStrategyOverride ? player.strategy.plannedStops[player.pitsDone] : undefined
  if (next) return next.compound
  return bestDryCompound(config, state.totalLaps - state.lap)
}

export function detectRadioRequest(
  state: RaceState,
  config: RaceConfig,
  tracker: RequestTracker,
  ctx: RequestContext,
): { request: RadioRequest | null; tracker: RequestTracker } {
  const rr = config.tuning.radioRequests
  const player = state.cars.find(c => c.isPlayer)
  if (!player || player.retired || state.sector !== 0 || state.lap === 0 ||
      state.lap === tracker.lastLapSeen || state.lap >= state.totalLaps) {
    return { request: null, tracker }
  }
  const t: RequestTracker = { ...tracker, lastAskedLap: { ...tracker.lastAskedLap }, lastLapSeen: state.lap }

  // The push streak is tracked at every lap end, asked or not.
  const ahead = state.cars.find(c => !c.retired && c.position === player.position - 1) ?? null
  const gap = ahead ? player.raceTime - ahead.raceTime : Number.POSITIVE_INFINITY
  if (ahead && gap <= rr.pushGap) {
    t.closeLapEnds = t.closeAheadId === ahead.driverId ? t.closeLapEnds + 1 : 1
    t.closeAheadId = ahead.driverId
  } else {
    t.closeLapEnds = 0
    t.closeAheadId = null
  }

  const kind = neutralisationKind(state.safetyCar)
  if (ctx.pending || t.asked >= rr.maxPerRace) return { request: null, tracker: t }

  const spec = config.compounds[player.compound]
  const driver = config.drivers.find(d => d.id === player.driverId)
  const cliff = spec && driver ? tyreCliffFraction(spec, effectiveTyreAge(player, driver, state.weatherState, config.tuning)) : 0
  const lapsLeft = state.totalLaps - state.lap

  // Box: "Tyres are gone, can we box?"
  const next = config.playerStrategyOverride ? player.strategy.plannedStops[player.pitsDone] : undefined
  const planSoon = next !== undefined && next.lap - player.lap <= rr.boxPlanWindowLaps
  if (cliff >= rr.boxCliffFrac && !planSoon && lapsLeft > rr.minLapsLeft &&
      !ctx.inPit && !ctx.pitPanelOpen && t.boxAskedAtPits !== player.pitsDone &&
      state.lap - t.lastAskedLap.box >= rr.cooldownLaps) {
    t.asked++
    t.lastAskedLap.box = state.lap
    t.boxAskedAtPits = player.pitsDone
    return { request: { kind: 'box', lap: state.lap, aheadId: null, compound: boxRequestCompound(config, state) }, tracker: t }
  }

  // Push: "I'm faster than {ahead}, let me push". Never under a neutralisation (ruling R6).
  if (ahead && kind === null && t.closeLapEnds >= rr.pushLapEnds && player.paceMode !== 'push' &&
      cliff < rr.pushMaxCliffFrac && state.lap - t.lastAskedLap.push >= rr.cooldownLaps) {
    const mine = lastLapTime(state, player.driverId)
    const theirs = lastLapTime(state, ahead.driverId)
    if (mine !== null && theirs !== null && theirs - mine >= rr.pushPaceMargin) {
      t.asked++
      t.lastAskedLap.push = state.lap
      return { request: { kind: 'push', lap: state.lap, aheadId: ahead.driverId, compound: null }, tracker: t }
    }
  }
  return { request: null, tracker: t }
}
```

```tsx
/**
 * The driver asks a yes/no question (spec 2026-10-17 §2). Above the HUD alert;
 * the race keeps running. The countdown runs only while the race clock does
 * (ruling R7); at zero it is a NO.
 */
function RequestCard({ req }: { req: ActiveRadioRequest }) {
  const answer = useRaceStore(s => s.answerRadioRequest)
  const dismiss = useRaceStore(s => s.dismissRadioRequest)
  const expiryMs = useRaceStore(s => (s.config?.tuning.radioRequests.expirySec ?? 8) * 1000)
  const racing = useRaceStore(s => s.phase === 'racing')
  const clockRunning = useClockStore(s => s.speed > 0 && s.appVisible)
  const running = racing && clockRunning
  const reduced = useReducedMotion()
  const { impact } = useHaptics()
  const [left, setLeft] = useState(expiryMs)

  // One buzz on arrival: the card has a new id every time.
  useEffect(() => { impact(ImpactStyle.Medium) }, []) // eslint-disable-line react-hooks/exhaustive-deps
  useEffect(() => {
    if (!running) return
    const t = setInterval(() => setLeft(l => l - TICK_MS), TICK_MS)
    return () => clearInterval(t)
  }, [running])
  useEffect(() => { if (left <= 0) dismiss() }, [left, dismiss])

  const yesLabel = req.kind === 'box' ? `Yes, box for ${TYRE_NAME[req.compound ?? 'M']}` : 'Yes, push'
  const frac = Math.max(0, Math.min(1, left / expiryMs))

  return (
    <motion.div
      data-testid="radio-request"
      role="group"
      aria-label="Driver radio request"
      initial={reduced ? { opacity: 0 } : { opacity: 0, x: -18 }}
      animate={reduced ? { opacity: 1 } : { opacity: 1, x: 0 }}
      exit={reduced ? { opacity: 0 } : { opacity: 0, x: 18 }}
      transition={{ duration: 0.18, ease: EASE }}
      className="slant-lg"
      style={{
        margin: '8px 8px 0', padding: '8px 10px 0 18px', flexShrink: 0,
        background: 'var(--grape)', color: 'var(--white)',
        display: 'flex', flexDirection: 'column', gap: 6,
      }}

      {/* Announced once, assertively: it is a question with a deadline. */}
      <span role="alert" style={VISUALLY_HIDDEN}>{`Driver radio: ${req.line}`}</span>
      <div style={{ display: 'flex', alignItems: 'center', gap: 8 }}>
        <span style={{ fontFamily: 'var(--font-display)', fontWeight: 900, fontStyle: 'italic', fontSize: 15, color: 'var(--lilac-dim)', flexShrink: 0 }}>
          DRIVER
        </span>

          YES
        </KitButton>
        <KitButton variant="secondary" size="sm" ariaLabel="No" onClick={() => answer(false)} style={{ height: 48, minWidth: 56 }}>
          NO
        </KitButton>
      </div>
      <div style={{ height: 3, background: 'var(--ink)', marginBottom: 6 }}>

        />
      </div>

  )
}
```

```ts
import type { RaceConfig, RaceState, WeatherState } from './types'

/**
 * The weather strip's forecast (spec 2026-10-17 §3): honest but imprecise.
 * Pure, no rng. `fromLap`/`toLap` are laps AHEAD of the current lap (1 = the
 * next lap), inclusive, and always contain the true change lap (ruling R9).
 */
export type WeatherForecast =
  | { kind: 'steady' }
  | { kind: 'rain' | 'drying'; fromLap: number; toLap: number; chance: number }

const SEVERITY: Record<WeatherState, number> = { DRY: 0, DAMP: 1, WET: 2 }

/**
 * A fixed shift in [-1, 1) for one change in one race, hashed from the seed and
 * the ABSOLUTE lap of the change -- so the window keeps its side as the change
 * approaches instead of jumping about lap to lap. Same integer finaliser as
 * raceStore's projectionSeed.
 */
export function forecastOffset(seed: number, changeLap: number): number {
  let h = (seed ^ Math.imul(changeLap + 1, 0x9E3779B1)) >>> 0
  h = Math.imul(h ^ (h >>> 16), 0x85EBCA6B) >>> 0
  h = Math.imul(h ^ (h >>> 13), 0xC2B2AE35) >>> 0
  h = (h ^ (h >>> 16)) >>> 0
  return (h / 4294967296) * 2 - 1
}

export function forecast(
  state: RaceState,
  config: RaceConfig,
  horizon: number = config.tuning.weather.forecastHorizon,
): WeatherForecast {
  const w = config.tuning.weather
  // Laps still to start after the current one. 0 on the last lap and after the flag.
  const lapsLeft = state.totalLaps - state.lap - 1
  if (!(lapsLeft > 0)) return { kind: 'steady' }
  const now = state.weatherState
  const reach = Math.min(horizon, lapsLeft)
  for (let d = 1; d <= reach; d++) {
    const at = state.weatherTimeline[state.lap + d]
    if (at === undefined) break
    if (SEVERITY[at] === SEVERITY[now]) continue
    const half = w.forecastSpread[Math.min(d, w.forecastSpread.length - 1)] ?? 0
    const shift = Math.round(forecastOffset(config.seed, state.lap + d) * half)
    const raw = w.forecastConfidence[Math.min(d, w.forecastConfidence.length - 1)] ?? 0
    return {
      kind: SEVERITY[at] > SEVERITY[now] ? 'rain' : 'drying',
      fromLap: Math.max(1, d - half + shift),
      toLap: Math.min(lapsLeft, d + half + shift),
      chance: Math.round(raw * 20) / 20,
    }
  }
  return { kind: 'steady' }
}
```

`!(lapsLeft > 0)` also catches a malformed state whose `totalLaps` is missing (NaN).

```tsx
function useForecast(): { now: WeatherState; f: WeatherForecast } | null {
```

> **Ruling recorded for Veet (R11): the stoppage, in engine terms.**
> - **Trigger.** The roll happens on a tick whose FIRST retirement is a crash (the same trigger the SC roll uses). It happens only while fewer than `maxPerRace` red flags have been shown, and only with more than `minLapsLeft` laps left counting the current one (`totalLaps − lap > 5`). All three eligibility checks come BEFORE the draw.
> - **Superseding.** A red flag supersedes a running SC or VSC: `safety_car_ended`/`vsc_ended` is logged first, so every lap-chart period closes. Nothing supersedes a red flag, and no SC, VSC or second red flag is rolled under one.
> - **While it is out.** Cars run at the safety car's pace (`incidents.safetyCar.paceMultiplier`) and overtaking is suspended. A stop would cost the SC lane price, but none is made: AI decisions and plan stops are skipped at every lap boundary while it is out, because the free change replaces them.
> - **When the restart happens.** At the first lap boundary AFTER the tick that showed it. A red flag shown on the lap-completing tick (sector 2) therefore waits a whole lap, so the player always gets a decision (Task 11).
> - **Who chooses which tyre.** The restart lap's weather picks the family. On a DRY restart, a planned stop within `planWindowLaps` is fitted and consumed (`pitsDone + 1`). Otherwise the car gets fresh tyres of its current compound, or `bestDryCompound` if it is on wets. On a non-dry restart it is W on WET or I on DAMP, and the plan is not consumed, because a dry plan compound is wrong in the rain. A car with no sets of any kind left keeps its tyres. A player with no chosen plan (no `playerStrategyOverride`) has no plan to consume.
> - **Regrid.** The order is the order by `raceTime` at that boundary. `raceTime` becomes leader + (pos − 1) × `qualifying.gridSlotGapSec`. Retired cars are frozen.

```ts
import type { RaceConfig, CarState, Compound, WeatherState } from './types'
import { resolveAllocatedCompound, consumeTyreSet } from './tyres'
import { bestDryCompound } from './strategy'

/**
 * Which tyre a car gets at the red-flag restart (spec 2026-10-17 §4, ruling
 * R11), and whether that change consumes its next planned stop. `car.lap` is
 * the lap about to start. `chosen` is the player's restart_tyre call (Task 10).
 */
export function restartTyre(
  config: RaceConfig, car: CarState, weather: WeatherState, lapsLeft: number, chosen?: Compound,
): { compound: Compound; consumesPlan: boolean } {
  // The engine never executes the team default for the player; only a chosen plan.
  const plan = car.isPlayer && !config.playerStrategyOverride ? [] : car.strategy.plannedStops
  const next = plan[car.pitsDone]
  const inWindow = next !== undefined && next.lap - car.lap <= config.tuning.incidents.redFlag.planWindowLaps
  const consumesPlan = inWindow && weather === 'DRY'
  if (chosen !== undefined) return { compound: chosen, consumesPlan }
  if (weather === 'WET') return { compound: 'W', consumesPlan: false }
  if (weather === 'DAMP') return { compound: 'I', consumesPlan: false }
  if (consumesPlan) return { compound: next!.compound, consumesPlan: true }
  if (config.compounds[car.compound]?.type === 'dry') return { compound: car.compound, consumesPlan: false }
  return { compound: bestDryCompound(config, lapsLeft), consumesPlan: false }
}

/**
 * The restart, in one step: order frozen as it stands, raceTime re-gridded to
 * leader + (pos - 1) x qualifying.gridSlotGapSec (the start-grid gap), and a
 * free tyre change for every running car -- no stop time; pitsDone + 1 only
 * when a planned stop is consumed. Retired cars are frozen. Pure.
 */
export function applyRedFlagRestart(
  config: RaceConfig, cars: CarState[], weather: WeatherState, lapsLeft: number, playerChoice?: Compound,
): CarState[] {
  const gap = config.tuning.qualifying.gridSlotGapSec
  const order = cars.filter(c => !c.retired).sort((a, b) => a.raceTime - b.raceTime)
  const leader = order[0]?.raceTime ?? 0
  const slot = new Map(order.map((c, i) => [c.driverId, i]))
  return cars.map(car => {
    const i = slot.get(car.driverId)
    if (i === undefined) return car
    const regridded: CarState = { ...car, raceTime: leader + i * gap }
    const { compound, consumesPlan } = restartTyre(config, car, weather, lapsLeft, car.isPlayer ? playerChoice : undefined)
    const resolved = resolveAllocatedCompound(compound, car.tyreAllocation)
    if (!resolved) return regridded      // no sets of any kind left: it restarts on what it has
    return {
      ...regridded,
      compound: resolved,
      tyreAge: 0,
      pitsDone: car.pitsDone + (consumesPlan ? 1 : 0),
      tyreAllocation: consumeTyreSet(car.tyreAllocation, resolved),
      compoundsUsed: [...car.compoundsUsed, resolved],
    }
  })
}
```

```ts
import { useRaceStore } from '@state/raceStore'
import { defaultRestartCompound } from '@engine/redFlag'

/**
 * Drives the live race store to the flag the way the app does: steps while
 * racing, answers a red-flag card with the default tyre, and runs the lights.
 * `before` runs before each step (make calls there), `after` after it. Bounded:
 * returns the number of steps taken; callers assert the terminal phase.
 */
export function driveToFlag(
  maxSteps: number,
  hooks: { before?: (n: number) => void; after?: (n: number) => void } = {},
): number {
  const r = () => useRaceStore.getState()
  let n = 0
  for (let guard = 0; guard < maxSteps * 2 && n < maxSteps; guard++) {
    const phase = r().phase
    if (phase === 'finished' || phase === 'idle') break
    if (phase === 'red_flag') { r().confirmRedFlagRestart(defaultRestartCompound(r().config!, r().raceState!)); continue }
    if (phase === 'starting') { r().confirmRaceStart(); continue }
    hooks.before?.(n)
    r().step()
    n++
    hooks.after?.(n)
  }
  return n
}
```

```ts
import type { SafetyCarState } from '@engine/types'
import type { RacePhase } from '@state/raceStore'
import { neutralisationKind } from '@engine/incidents'

/**
 * The track canvas's caution wash. Deliberately modest (spec section 6 surface
 * 5: the banner is the signal, this is atmosphere). The VSC wash is about half
 * the SC's so the two are distinguishable at a glance (spec 1.5 §1); a red flag
 * washes hot and stronger (spec 1.6 §4).
 *
 * Gated on phase because a race can END under a neutralisation and the canvas
 * renders in every phase except idle -- the results screen must not sit under
 * an unexplained wash. The red-flag card's phase keeps the wash behind it.
 */
export const SC_WASH_ALPHA = 0.05
export const VSC_WASH_ALPHA = 0.025
export const RED_WASH_ALPHA = 0.08

/** 0xFF4F84 mirrors --hot and 0xFFB020 mirrors --caution in src/styles/tokens.css -- change them together. */
export function cautionWashColor(safetyCar: SafetyCarState | null): number {
  return neutralisationKind(safetyCar) === 'red' ? 0xFF4F84 : 0xFFB020
}

export function cautionWashAlpha(safetyCar: SafetyCarState | null, phase: RacePhase): number {
  if (phase !== 'racing' && phase !== 'starting' && phase !== 'red_flag') return 0
  const kind = neutralisationKind(safetyCar)
  switch (kind) {
    case null: return 0
    case 'sc': return SC_WASH_ALPHA
    case 'vsc': return VSC_WASH_ALPHA
    case 'red': return RED_WASH_ALPHA
    default: { const never: never = kind; return never }
  }
}
```
