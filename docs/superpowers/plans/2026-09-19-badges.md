# In-Game Badges Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fifteen cosmetic badges derived from career history, shown in a trophy case on the career screen and announced by a toast at the race result.

**Architecture:** One append-only `raceLog` on the career record; every badge is a pure predicate over that record. Badges persist nothing of their own, so the trophy case cannot disagree with the stats screen and nothing can be awarded twice. The simulation engine is not touched.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess`), Zustand, zod, React 19, framer-motion (`motion/react`), Vitest + React Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-19-badges-design.md`

## Global Constraints

- **`CAREER_SAVE_VERSION` STAYS `1`.** `CareerSnapshotSchema` pins `v: z.literal(CAREER_SAVE_VERSION)` and `loadCareer` discards any save that fails to parse. Bumping the version wipes every existing career. New fields are added with a zod `.default()`.
- **The engine is untouched.** Nothing under `src/engine/` is created or modified. `src/state/badges.ts` imports no store, no React, no Zustand.
- **No `color-mix()`.** minSdk 30 ships Chromium 91; the value is dropped, not approximated. Use `rgba(var(--token-rgb), <alpha>)`, or `linear-gradient(<rgba>, <rgba>), <solid>` to tint an opaque surface. Guarded by `tests/ui/colorMixBan.test.ts`.
- **No remote URLs anywhere in `src/`.** Guarded by `tests/ui/noRemoteAssets.test.ts`.
- **Colour via tokens only.** No new raw hex and no new `rgba(...)` literals with hardcoded channel numbers — the repo already carries ~20 as debt.
- **All live-updating numbers use `var(--font-mono)` with `fontVariantNumeric: 'tabular-nums'`.**
- **Reduced motion:** read `useSettingsStore(s => s.reducedMotion)`, never `matchMedia` directly. Replace movement with opacity; never suppress content.
- **Colour is never the only signal** (CLAUDE.md §6.3).
- **Run `npx tsc --noEmit` as well as the test suite.** Vitest does not typecheck.

### Task 1: The badge module

**Files:**
- Create: `src/state/badges.ts`
- Test: `tests/state/badges.test.ts`

**Interfaces:**
- Consumes: **nothing from the store.** `badges.ts` declares `BadgeInput`, the slice of the career record it reads, instead of importing `CareerRecord`.
- Produces: `RaceFact`, `BadgeInput`, `BadgeDef`, `BADGES`, `earnedBadges(r)`, `newlyEarned(before, after)`.

**Why `BadgeInput` rather than importing `CareerRecord`:** two reasons, and both matter.

1. **No import edge back to the store.** `careerStore` imports `newlyEarned` from this module as a VALUE in Task 3. If this module imported `careerStore` in return — even as a type — the edge exists for someone to later make into a value import, closing an ESM cycle. The same constraint is documented at `src/state/buildRaceConfig.ts:25` and in the header of `careerStore.ts`.
2. **Task 1 stays green on its own.** `CareerRecord` has no `raceLog` until Task 2. Declaring the input shape here means this task typechecks and tests before the store changes at all.

`CareerRecord` is structurally assignable to `BadgeInput`, so Task 3 passes the record straight in with no adapter.

```ts
// src/state/badges.ts
/**
 * Badges: fifteen cosmetic records of what the player has done.
 *
 * Every badge is a PURE PREDICATE over the career record. Nothing about a
 * badge is persisted -- no "earned" list, no flags. That is deliberate: a
 * stored earned-list is a second source of truth that drifts from the stats
 * it claims to summarise, can award twice, and cannot retroactively grant a
 * badge added later. Deriving instead means the trophy case and the stats
 * screen above it are reading the same numbers, always.
 *
 * This module is pure. It imports no store, no React and no Zustand, so it
 * unit-tests directly. It also declares the shape it READS (BadgeInput)
 * rather than importing CareerRecord, so there is no import edge back to
 * careerStore at all -- careerStore imports this module as a value, and the
 * reverse edge would be a cycle waiting for someone to make it a value
 * import. Same class of constraint as src/state/buildRaceConfig.ts:25.
 */

/** One race, as it happened. Every field is already computed at the
 *  recordRace call site in seasonStore -- nothing new is simulated. */
export interface RaceFact {
  /** careerRecord.seasonNumber at the time. */
  season: number
  /** seasonStore.raceIndex, 0-based. */
  round: number
  /** 1-based grid slot, from qualifyingResult.order. */
  grid: number
  /** 1-based classified finishing position. */
  finish: number
  retired: boolean
  pole: boolean
  stops: number
  overtakes: number
  wet: boolean
}

/**
 * The slice of the career record badges read.
 *
 * CareerRecord is structurally assignable to this, so callers pass the record
 * directly. Declaring it here rather than importing keeps this module free of
 * any dependency on the store.
 */
export interface BadgeInput {
  titles: number
  wins: number
  podiums: number
  poles: number
  racesStarted: number
  bestFinish: number | null
  raceLog: readonly RaceFact[]
}

export interface BadgeDef {
  id: string
  name: string
  /** Shown on the LOCKED badge. A locked badge whose requirement is hidden is
   *  a mystery box, not a goal. */
  condition: string
  earned: (r: BadgeInput) => boolean
}

/** A DNF is never a win, whatever position it was classified in. */
function won(f: RaceFact): boolean {
  return !f.retired && f.finish === 1
}

/** Longest run of consecutive races finished. A fold, not a counter --
 *  see the spec, §2.2. */
function longestFinishStreak(log: readonly RaceFact[]): number {
  let best = 0
  let run = 0
  for (const f of log) {
    if (f.retired) { run = 0; continue }
    run += 1
    if (run > best) best = run
  }
  return best
}

export const BADGES: readonly BadgeDef[] = [
  // Milestones -- derived from fields that already exist, so an existing
  // career earns these retroactively the moment the screen appears.
  { id: 'in_the_points', name: 'In The Points', condition: 'Finish in the top 10',
    earned: r => r.bestFinish !== null && r.bestFinish <= 10 },
  { id: 'rostrum', name: 'Rostrum', condition: 'Finish on the podium',
    earned: r => r.podiums >= 1 },
  { id: 'winner', name: 'Winner', condition: 'Win a race',
    earned: r => r.wins >= 1 },
  { id: 'pole_position', name: 'Pole Position', condition: 'Qualify on pole',
    earned: r => r.poles >= 1 },
  { id: 'champion', name: 'Champion', condition: 'Win the championship',
    earned: r => r.titles >= 1 },
  { id: 'dynasty', name: 'Dynasty', condition: 'Win three championships',
    earned: r => r.titles >= 3 },
  { id: 'double_figures', name: 'Double Figures', condition: 'Win 10 races',
    earned: r => r.wins >= 10 },
  { id: 'veteran', name: 'Veteran', condition: 'Start 50 races',
    earned: r => r.racesStarted >= 50 },
  { id: 'centurion', name: 'Centurion', condition: 'Start 100 races',
    earned: r => r.racesStarted >= 100 },

  // Event badges -- fold over the log, so they count from the first race
  // logged. They cannot be retroactive: the facts were never recorded.
  { id: 'storm_chaser', name: 'Storm Chaser', condition: 'Win a wet race',
    earned: r => r.raceLog.some(f => f.wet && won(f)) },
  { id: 'comeback', name: 'Comeback', condition: 'Win from P10 or worse',
    earned: r => r.raceLog.some(f => f.grid >= 10 && won(f)) },
  { id: 'lights_to_flag', name: 'Lights To Flag', condition: 'Take pole and win the same race',
    earned: r => r.raceLog.some(f => f.pole && won(f)) },
  { id: 'one_stop_wonder', name: 'One-Stop Wonder', condition: 'Win using exactly one pit stop',
    earned: r => r.raceLog.some(f => f.stops === 1 && won(f)) },
  { id: 'ironman', name: 'Ironman', condition: 'Finish 12 races in a row',
    earned: r => longestFinishStreak(r.raceLog) >= 12 },
  { id: 'damage_limitation', name: 'Damage Limitation', condition: 'Score points from P15 or worse',
    earned: r => r.raceLog.some(f => !f.retired && f.grid >= 15 && f.finish <= 10) },
]

/** Ids of every badge the record satisfies. */
export function earnedBadges(r: BadgeInput): string[] {
  return BADGES.filter(b => b.earned(r)).map(b => b.id)
}

/**
 * Ids earned by `after` but not by `before`.
 *
 * A set difference over two pure evaluations is what makes "announce it once"
 * fall out of the design instead of needing an `announced` flag kept in sync.
 */
export function newlyEarned(before: BadgeInput, after: BadgeInput): string[] {
  const had = new Set(earnedBadges(before))
  return earnedBadges(after).filter(id => !had.has(id))
}
```

```tsx
// src/ui/BadgeCase.tsx

/**
 * The trophy case.
 *
 * Renders every badge, earned and unearned, and shows the CONDITION on the
 * locked ones -- a locked badge whose requirement is hidden is a mystery box
 * rather than something to chase.

 * Earned state is carried by fill, border and an aria-label as well as

export function BadgeCase() {
  const record = useCareerStore()
  const earned = new Set(earnedBadges(record))

  return (

      <div style={{
        display: 'flex', alignItems: 'baseline', justifyContent: 'space-between',

        <div style={{
          fontFamily: 'var(--font-mono)', fontVariantNumeric: 'tabular-nums',
          fontSize: 11, color: 'var(--text-mid)',
        }}>
          {earned.size} / {BADGES.length}
        </div>
      </div>

      <div style={{ display: 'grid', gridTemplateColumns: 'repeat(2, 1fr)', gap: 8 }}>
        {BADGES.map(b => {
          const got = earned.has(b.id)
          return (
            <div
              key={b.id}
              data-testid={`badge-${b.id}`}
              data-earned={got ? 'true' : 'false'}
              aria-label={`${b.name} — ${got ? 'earned' : `locked: ${b.condition}`}`}

                borderRadius: 8, padding: '10px 12px',
                border: `1px solid ${got ? 'var(--accent)' : 'var(--line-hair)'}`,
```

```tsx
// src/ui/BadgeToast.tsx
import { motion, AnimatePresence } from 'framer-motion'
import { useEffect } from 'react'
import { useCareerStore } from '@state/careerStore'
import { useSettingsStore } from '@state/settingsStore'
import { useHaptics } from '@hooks/useHaptics'
import { ImpactStyle } from '@capacitor/haptics'
import { BADGES } from '@state/badges'

/**
 * Announces badges earned by the race just finished.
 *
 * Reads justEarned, which careerStore computes as a set difference at the one
 * moment both the before and after records exist. That is why this fires once
 * without an `announced` flag to keep in sync, and why it does not re-fire
 * when the app is reopened -- justEarned is never saved.
 *
 * Haptic via useHaptics directly and NOT useUiTap: that helper also plays the
 * navTap sound, which is the acknowledgement of a press. A badge arriving is
 * not a press.
 */
export function BadgeToast() {
  const justEarned = useCareerStore(s => s.justEarned)
  const reducedMotion = useSettingsStore(s => s.reducedMotion)
  const { impact } = useHaptics()

  // An id with no definition is ignored rather than rendered blank: the
  // post-race screen has no way out, so it must not crash on stale data.
  const earned = justEarned
    .map(id => BADGES.find(b => b.id === id))
    .filter((b): b is NonNullable<typeof b> => b !== undefined)

  useEffect(() => {
    if (earned.length > 0) void impact(ImpactStyle.Medium)
    // Fires once per set of newly earned badges.
  }, [earned.length, impact])

  if (earned.length === 0) return null

  return (
    <div style={{
      position: 'absolute', left: 0, right: 0, bottom: 'calc(var(--safe-bottom) + 16px)',
      display: 'flex', flexDirection: 'column', gap: 8, alignItems: 'center',
      pointerEvents: 'none', zIndex: 5,
    }}>
      <AnimatePresence>
        {earned.map((b, i) => (
          <motion.div
            key={b.id}
            initial={reducedMotion ? { opacity: 0 } : { opacity: 0, y: 24 }}
            animate={{ opacity: 1, y: 0 }}
            exit={reducedMotion ? { opacity: 0 } : { opacity: 0, y: 12 }}
            transition={{ delay: reducedMotion ? 0 : i * 0.35, duration: 0.3 }}
            style={{
              borderRadius: 10, padding: '10px 16px',
              border: '1px solid var(--accent)',
              background: 'linear-gradient(rgba(var(--accent-rgb), 0.12), rgba(var(--accent-rgb), 0.12)), var(--bg-elevated)',
              textAlign: 'center', maxWidth: '86%',
            }}
          >
            <div style={{
              fontFamily: 'var(--font-display)', fontSize: 9, letterSpacing: '0.2em',
              color: 'var(--text-dim)',
            }}>
              BADGE EARNED
            </div>
            <div style={{
              fontFamily: 'var(--font-display)', fontSize: 16, fontWeight: 700,
              color: 'var(--accent)', marginTop: 1,
            }}>
              {b.name}
            </div>
          </motion.div>
        ))}
      </AnimatePresence>
    </div>
  )
}
```
