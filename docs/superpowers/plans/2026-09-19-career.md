# Multi-Season Career Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a career layer above the season so a championship is the start of something rather than a factory reset.

**Architecture:** A new `careerStore` owns only what outlives a season — a record of titles/wins/poles and a season number — and saves to its own Preferences key so an abandoned season never costs the career. `seasonStore` keeps owning `purchasedTiers` and `rivalDevelopment`; the career's job at a season boundary is to *transform* them (erode the player's, escalate the rivals') rather than to hold them. The race seed gains a season term written as `(season - 1)` so season 1 stays byte-identical to today.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess`), Zustand, Vitest, zod, React, Framer Motion (`motion/react`), Capacitor Preferences.

**Spec:** `docs/superpowers/specs/2026-09-19-career-design.md`

## Global Constraints

- **Engine purity (CLAUDE.md §3):** `src/engine/` imports nothing from `state/`, `ui/`, `canvas/` or `hooks/`. This feature touches NO engine file except by passing different numbers into existing ones.
- **Season 1 must remain byte-identical to today.** `currentSeed()` at `seasonNumber: 1` returns exactly today's value. This protects `tests/engine/byteIdentity.test.ts`, the Monte-Carlo bands in `MODEL_SPEC.md` §10.1 and all three scenarios in `src/data/scenarios.json`.
- **No tuning constants in code.** All balance numbers live in `src/data/tuning.json` and are zod-validated in `src/data/validators.ts`. Adding a key to `tuning.json` ALSO requires adding it to the `TuningConstants` type in `src/engine/types.ts` — the schema and the type are separate and both are needed, or `tsc` fails.
- **`color-mix()` is banned.** minSdkVersion is 30; API 30's factory WebView is Chromium 91 and color-mix needs 111. Use `rgba(var(--token-rgb), <alpha>)`, or `linear-gradient(<rgba>, <rgba>), <solid>` to tint an opaque surface. Enforced by `tests/ui/colorMixBan.test.ts`.
- **No raw hex in components.** Colour via tokens in `src/styles/tokens.css` only.
- **All live-updating numbers use `fontVariantNumeric: 'tabular-nums'`.**
- **Reduced motion** comes from `useSettingsStore(s => s.reducedMotion)`, never `window.matchMedia`.
- **Colour is never the only signal** (CLAUDE.md §6.3).
- **`vitest` does not typecheck.** Run `npx tsc --noEmit` separately before every commit.
- **Destructive actions are confirmed.** `endCareer` deletes a career permanently and must not be one tap from a primary button.

```ts
    const s = () => useCareerStore.getState()
    s().recordRace({ position: 1, retired: false, pole: true })
    s().recordRace({ position: 3, retired: false, pole: false })

    expect(s().podiums, 'a win is also a podium').toBe(2)
    expect(s().poles).toBe(1)
    expect(s().bestFinish).toBe(1)

     * recordRaceResult already scores a DNF as 0 points regardless of
     * classified position, and the career must agree. A car classified P3
     * because seventeen others retired behind it did not stand on a podium.

    expect(s().wins).toBe(0)

    expect(s().titles).toBe(1)
    expect(s().seasonNumber, 'two rollovers means season 3').toBe(3)
    expect(s().seasonHistory).toHaveLength(2)

  it('SEASON HISTORY RECORDS THE WINS THAT SEASON, NOT THE CAREER TOTAL', () => {
    /*
     * seasonStore does not count wins, so it passes 0 and careerStore fills it
     * in from its own season-scoped counter. Without the reset at rollover,
     * every season in the history would show the running career total instead
     * of what that season was actually worth.

    s().recordRace({ position: 1, retired: false, pole: false })

     * rather than left in a spec comment. Maxed is 3 tiers on 5 attributes.
     * Losing `tierDecayPerSeason` from each costs more to rebuy than a season
     * earns, so the player must choose what to keep at the top.

    expect(s().seasonNumber).toBe(1)

    s().endCareer()
    expect(s().hasCareer).toBe(false)
    expect(s().wins).toBe(0)
    expect(s().seasonHistory).toEqual([])
  })
```

```ts
import { create } from 'zustand'
import { loadGameData } from '@data/validators'

/**
 * The career: the layer above a season that owns what survives one.
 *
 * It deliberately does NOT own purchasedTiers or rivalDevelopment. Those are
 * read every race and live on seasonStore; the career's job at a boundary is to
 * TRANSFORM them and hand them back. That is also why rollOverSeason returns
 * the eroded tiers instead of writing them: seasonStore imports this module as
 * a value, so a value import back would close an ESM cycle -- the same
 * constraint documented at src/state/buildRaceConfig.ts:25.
 */

export interface SeasonSummary {
  seasonNumber: number
  teamId: string
  driverId: string
  championshipPosition: number
  points: number
  wins: number
}

export interface CareerRecord {
  /** 1-based. A career's first season is 1, and season 1 must seed exactly as today. */
  seasonNumber: number
  titles: number
  /** Career wins, across every season. */
  wins: number
  /** Wins in the CURRENT season only; reset at each rollover so SeasonSummary
   *  can record what the season was actually worth. */
  seasonWins: number
  podiums: number
  poles: number
  racesStarted: number
  /** Lowest position number achieved; null before any race. */
  bestFinish: number | null
  seasonHistory: SeasonSummary[]
}

const FRESH: CareerRecord = {
  seasonNumber: 1, titles: 0, wins: 0, seasonWins: 0, podiums: 0, poles: 0,
  racesStarted: 0, bestFinish: null, seasonHistory: [],
}

/** Each attribute drops by at most `decay` tiers, floored at 0. */
export function erodeTiers(
  tiers: Record<string, number>, decay: number,
): Record<string, number> {
  const out: Record<string, number> = {}
  for (const [id, owned] of Object.entries(tiers)) {
    out[id] = Math.max(0, owned - decay)
  }
  return out
}

/**
 * One off-season boost for every rival.
 *
 * It reuses the SAME pool constant the per-race accrual uses, so the winter
 * counts as a number of extra races rather than a second economy to tune.
 * Winning the title buys the grid a bigger winter -- a single legible step, not
 * a continuous function of margin, because a smooth rubber band keyed to how
 * well the player drives is the kind of mechanic players detect and resent.
 */
export function escalateRivals(
  current: Record<string, number>, wonTitle: boolean,
): Record<string, number> {
  const { cars, upgrades, tuning } = loadGameData()
  const { poolPerRace, facets } = upgrades.rivalDevelopment
  const { base, championBonus } = tuning.career.rivalCatchUp
  const winterRaces = base + (wonTitle ? championBonus : 0)

  const next = { ...current }
  for (const team of cars.teams) {
    const rate = team.developmentRate ?? 1.0
    next[team.id] = (next[team.id] ?? 0) + poolPerRace * rate * facets.length * winterRaces
  }
  return next
}

interface CareerStore extends CareerRecord {
  hasCareer: boolean
  recordRace: (r: { position: number; retired: boolean; pole: boolean }) => void
  /**
   * Ends a season. Takes the player's current tiers and returns the eroded
   * ones -- it never reads or writes seasonStore, which is what keeps this
   * module free of the import cycle described in the header.
   */
  rollOverSeason: (
    s: SeasonSummary, tiers: Record<string, number>,
  ) => { erodedTiers: Record<string, number> }
  beginCareer: () => void
  endCareer: () => void
  resumeCareer: (snap: CareerRecord) => void
}

export const useCareerStore = create<CareerStore>((set, get) => ({
  ...FRESH,
  hasCareer: false,

  recordRace({ position, retired, pole }) {
    const s = get()
    // A DNF is never a win or a podium, matching recordRaceResult, which
    // already scores a retirement as 0 points regardless of classified
    // position. A car classified P3 because others retired behind it did not
    // stand on a podium.
    const scored = !retired
    const won = scored && position === 1
    set({
      racesStarted: s.racesStarted + 1,
      wins: s.wins + (won ? 1 : 0),
      seasonWins: s.seasonWins + (won ? 1 : 0),
      podiums: s.podiums + (scored && position <= 3 ? 1 : 0),
      poles: s.poles + (pole ? 1 : 0),
      bestFinish: scored
        ? (s.bestFinish === null ? position : Math.min(s.bestFinish, position))
        : s.bestFinish,
    })
  },

  rollOverSeason(summary, tiers) {
    const s = get()
    const { tierDecayPerSeason } = loadGameData().tuning.career
    set({
      seasonNumber: s.seasonNumber + 1,
      titles: s.titles + (summary.championshipPosition === 1 ? 1 : 0),
      // The caller cannot know this -- seasonStore does not count wins -- so
      // the store fills it in from its own season-scoped counter.
      seasonHistory: [...s.seasonHistory, { ...summary, wins: s.seasonWins }],
      seasonWins: 0,
    })
    return { erodedTiers: erodeTiers(tiers, tierDecayPerSeason) }
  },

  beginCareer() { set({ ...FRESH, hasCareer: true }) },
  endCareer() { set({ ...FRESH, hasCareer: false }) },
  resumeCareer(snap) { set({ ...snap, hasCareer: true }) },
}))
```

```ts
import { loadGameData } from '@data/validators'

    /*

     * The season term is written (season - 1) precisely so season 1 adds zero.
     */
    useCareerStore.setState({ seasonNumber: 1 })
    for (const raceIndex of [0, 5, 11]) {
      for (const attemptNonce of [0, 3]) {
        useSeasonStore.setState({ raceIndex, attemptNonce })

          .toBe(raceIndex * 1000 + 42 + attemptNonce * 7919)
      }
```

```ts
import { z } from 'zod'
import { useCareerStore, type CareerRecord } from './careerStore'

export const CAREER_SAVE_KEY = 'career.save'
export const CAREER_SAVE_VERSION = 1

const SeasonSummarySchema = z.object({
  seasonNumber: z.number(),
  teamId: z.string(),
  driverId: z.string(),
  championshipPosition: z.number(),
  points: z.number(),
  wins: z.number(),

export const CareerSnapshotSchema = z.object({
  v: z.literal(CAREER_SAVE_VERSION),
  seasonNumber: z.number(),
  titles: z.number(),
  wins: z.number(),
  // Saved because a career reloaded mid-season must still know what THIS
  // season is worth; without it the next rollover would record 0 wins.
  seasonWins: z.number(),
  podiums: z.number(),
  poles: z.number(),
  racesStarted: z.number(),
  bestFinish: z.number().nullable(),
  seasonHistory: z.array(SeasonSummarySchema),
})

export type CareerSnapshot = z.infer<typeof CareerSnapshotSchema>

/** Null when there is no career to save. Pure, so it is testable without Preferences. */
export function careerSnapshotFrom(
  r: CareerRecord & { hasCareer: boolean },
): CareerSnapshot | null {
  if (!r.hasCareer) return null
  return {
    v: CAREER_SAVE_VERSION,
    seasonNumber: r.seasonNumber,
    titles: r.titles,
    wins: r.wins,
    seasonWins: r.seasonWins,
    podiums: r.podiums,
    poles: r.poles,
    racesStarted: r.racesStarted,
    bestFinish: r.bestFinish,
    seasonHistory: r.seasonHistory,
  }
}

export async function saveCareer(snap: CareerSnapshot): Promise<void> {
  await Preferences.set({ key: CAREER_SAVE_KEY, value: JSON.stringify(snap) })
}

export async function clearCareer(): Promise<void> {
  await Preferences.remove({ key: CAREER_SAVE_KEY })
}

export async function loadCareer(): Promise<CareerSnapshot | null> {
  try {
    const { value } = await Preferences.get({ key: CAREER_SAVE_KEY })
    if (!value) return null
    const parsed = CareerSnapshotSchema.safeParse(JSON.parse(value))
    if (!parsed.success) {
      console.warn('[career] discarding unreadable save', parsed.error.issues[0]?.message)
      return null
    }
    return parsed.data
  } catch (err: unknown) {
    console.warn('[career] save could not be read — starting fresh', err)
    return null
  }
}

/** Mirrors startSeasonAutosave: subscribe, diff, write only on real change. */
export function startCareerAutosave(): () => void {
  let last: string | null = null
  return useCareerStore.subscribe((state) => {
    const snap = careerSnapshotFrom(state)
    if (!snap) {
      if (last !== null) { last = null; void clearCareer() }
      return
    }
    const serialised = JSON.stringify(snap)
    if (serialised === last) return
    last = serialised
    void saveCareer(snap)
  })
}
```

- [ ] **Step 1: Write the simulation script**

Create `scripts/simulate-career.ts`:

```ts
/**
 * Simulates N seasons of a consistently strong player to see whether erosion
 * and rival escalation actually hold a career open.
 *
 * Run: npx tsx scripts/simulate-career.ts
 */
import { erodeTiers, escalateRivals } from '../src/state/careerStore'
import { loadGameData } from '../src/data/validators'

const { attributes, tierCosts, income } = loadGameData().upgrades
const { tierDecayPerSeason } = loadGameData().tuning.career
const SEASONS = 10
const RACES = 12

// A strong player: spends every point on the cheapest available tier each
// season, and wins the title whenever their total tier count leads.
let tiers: Record<string, number> = Object.fromEntries(attributes.map(a => [a.id, 0]))
let rivals: Record<string, number> = {}

for (let season = 1; season <= SEASONS; season++) {
  let budget = income.perRace * RACES
  // Buy greedily, cheapest tier first.
  for (;;) {
    const affordable = attributes
      .map(a => ({ id: a.id, owned: tiers[a.id] ?? 0 }))
      .filter(x => x.owned < tierCosts.length)
      .map(x => ({ ...x, cost: tierCosts[x.owned]! }))
      .filter(x => x.cost <= budget)
      .sort((a, b) => a.cost - b.cost)
    const pick = affordable[0]
    if (!pick) break
    budget -= pick.cost
    tiers[pick.id] = pick.owned + 1
  }
  const total = Object.values(tiers).reduce((a, b) => a + b, 0)
  const maxTotal = attributes.length * tierCosts.length
  const rivalTotal = Object.values(rivals).reduce((a, b) => a + b, 0)
  const wonTitle = total >= maxTotal * 0.8

  console.log(
    `season ${String(season).padStart(2)}  tiers ${String(total).padStart(2)}/${maxTotal}` +
    `  unspent ${String(budget).padStart(3)}  rivalDev ${rivalTotal.toFixed(1).padStart(7)}` +
    `  ${wonTitle ? 'TITLE' : ''}`,
  )

  tiers = erodeTiers(tiers, tierDecayPerSeason)
  rivals = escalateRivals(rivals, wonTitle)
}
```

```ts
import { describe, it, expect } from 'vitest'
import { erodeTiers, escalateRivals } from '@state/careerStore'
import { loadGameData } from '@data/validators'

describe('an endless career does not flatten out', () => {
  it('A MAXED PLAYER CANNOT HOLD THE MAXIMUM FOREVER', () => {
    /*
     * The purpose of erosion. If a player who buys optimally every season can
     * sit at full tiers indefinitely, then "stats carry over" has turned the
     * back half of an endless career into a victory lap, and the Development
     * screen stops being a decision.
     */
    const { attributes, tierCosts, income } = loadGameData().upgrades
    const { tierDecayPerSeason } = loadGameData().tuning.career
    const maxTotal = attributes.length * tierCosts.length
    let tiers = Object.fromEntries(attributes.map(a => [a.id, tierCosts.length]))

    let everBelowMax = false
    for (let season = 0; season < 10; season++) {
      tiers = erodeTiers(tiers, tierDecayPerSeason)
      let budget = income.perRace * 12
      for (;;) {
        const pick = attributes
          .map(a => ({ id: a.id, owned: tiers[a.id] ?? 0 }))
          .filter(x => x.owned < tierCosts.length)
          .map(x => ({ ...x, cost: tierCosts[x.owned]! }))
          .filter(x => x.cost <= budget)
          .sort((a, b) => a.cost - b.cost)[0]
        if (!pick) break
        budget -= pick.cost
        tiers[pick.id] = pick.owned + 1
      }
      if (Object.values(tiers).reduce((a, b) => a + b, 0) < maxTotal) everBelowMax = true
    }
    expect(everBelowMax, 'erosion never bites -- the career flattens').toBe(true)
  })

  it('RIVAL DEVELOPMENT COMPOUNDS ACROSS SEASONS', () => {
    // playAgain discarded rivalDevelopment entirely. If this ever returns to
    // zero between seasons, "rivals get stronger every season" is gone.
    let rivals: Record<string, number> = {}
    const totals: number[] = []
    for (let s = 0; s < 5; s++) {
      rivals = escalateRivals(rivals, true)
      totals.push(Object.values(rivals).reduce((a, b) => a + b, 0))
    }
    for (let i = 1; i < totals.length; i++) {
      expect(totals[i]!).toBeGreaterThan(totals[i - 1]!)
    }
  })
})
```

## Notes for the implementer

- **The single most important assertion in this plan** is `SEASON 1 SEEDS EXACTLY AS IT DOES TODAY` (Task 3). If it fails, byte-identity, the Monte-Carlo bands and all three scenarios are wrong, and nothing else matters until it is fixed. It is written `(seasonNumber - 1)` for exactly this reason.
- **Mutation-check every test meant to guard a default or a floor.** This project has shipped unfailable tests before: a "sim speed" setting was dead for weeks with no test failing, and a qualifying double-count guard passed with the bug present because a confound masked it.
- **`vitest` does not typecheck, and nothing in the JS toolchain reads Android XML or gradle.** Run `npx tsc --noEmit` before every commit, and the release build before the final one.
- **Balance numbers are Veet's call** (CLAUDE.md §8). `tierDecayPerSeason` in particular decides whether erosion reads as tension or as confiscation. Surface it with the simulation output; do not tune it silently.
- **Do not add contracts, team changes or a driver market.** The player keeps their seat — spec §7. That cut is what keeps this sub-project small.
