# Pit Wall 2.0 "Content" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Pit Wall 2.0 "Content" in four releases: two new circuits with a repeatable authoring pipeline and night races (1.7), a challenges hub with a historic pack and a daily challenge (1.8), a start editor with shareable codes (1.9), and custom championships plus a day theme (2.0), without changing any existing race, save or Monte-Carlo band.

**Architecture:** New race behaviour enters only as new optional circuit data read through one pure helper (`circuitTraits`), whose neutral values are the old arithmetic, so the golden race and every shipped seed reproduce. Challenges are seeds: classics and the daily are discovered by the same first-hit/par rule as shipped scenarios; custom starts are *recipes* (config inputs + the player's calls + a lap) replayed by the deterministic engine and packed into a checksummed binary code. The custom championship is a `rules` mode of the existing `seasonStore`, persisted under its own key. The day theme redefines Race Day Bold tokens under `:root[data-theme="day"]` plus a few semantic tokens.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess`), React 19 + framer-motion, Zustand 5, zod 4, Vitest 4 (jsdom), PixiJS 8, Capacitor 8 (Android).

**Spec:** `docs/superpowers/specs/2026-10-24-v2-content-design.md` (binding; rulings R1–R29). Also read `CLAUDE.md` §3, §5, §6 and `MODEL_SPEC.md` §3, §10, §12.

## Global Constraints

- Same seed + same inputs ⇒ identical race. **This plan adds no rng draw.** Scaled probabilities keep the `chance > 0 && rng() < chance` idiom; a factor of exactly 1 is the identity.
- `tests/engine/byteIdentity.test.ts` and `tests/fixtures/golden-race-pre-incidents.json` pass unchanged and are **never re-captured**. bengaluru gets no engine-active field. `makeDeterministicTuning` pins `timeOfDay.nightWearFactor: 1`.
- Saves: season `SAVE_VERSION` 2, career 1, cloud 1 — **no bumps, and the career season snapshot gains no field.** New keys only: `custom.save` (v1), `starts.mine` (v1), `daily.best`, `settings.theme`. `tests/fixtures/season-save-1.4.json` / `career-save-1.4.json` keep loading.
- Every balance number in `src/data/tuning.json` or `circuits.json`, zod-bounded.
- Existing Monte-Carlo gates hold on `SAMPLE` and the career calendar; nothing is widened. New per-circuit gates live in `tests/engine/newCircuitBands.test.ts`.
- Scenarios (core, classics) are authored with `scripts/find-scenarios.ts`: first printed hit, goal = par − 1, blurb true. The daily applies the same rule at runtime.
- Race Day Bold tokens only. Volt = player / the one CTA. Text on volt/hot/caution/gain fills is `--on-accent` (from Task 25; before it, `--ink`). Tabular figures on live numbers. ≥ 44px controls with screen-reader labels. Colour never the only signal. Reduced motion respected. `color-mix()` banned.
- No new npm dependency and no new Android permission.
- Never two full `vitest run`s at once. Every loop in a test is bounded.
- Engine imports nothing from `state/`, `ui/`, `canvas/`. No `Math.random()` in `src/engine/` or in any generator in this plan.

Create `src/engine/circuitTraits.ts`:

```ts
import type { CircuitSpec, RaceConfig, TuningConstants } from './types'

/** What effectiveTyreAge needs to price wear: the tuning and the circuit raced. */
export type TyreContext = Pick<RaceConfig, 'tuning' | 'circuit'>

export interface CircuitTraits { wear: number; crashRisk: number; neutralisationRisk: number }

/**
 * The circuit's race-behaviour multipliers (spec 2026-10-24 §1.3). Every absent
 * field is exactly 1, so a circuit with no trait races exactly as before --
 * byteIdentity and every shipped seed depend on that. Pure, no rng.
 */
export function circuitTraits(circuit: CircuitSpec, tuning: TuningConstants): CircuitTraits {
  const night = circuit.timeOfDay === 'night' ? tuning.timeOfDay.nightWearFactor : 1
  return {
    wear: (circuit.tyreWear ?? 1) * night,
    crashRisk: circuit.crashRisk ?? 1,
    neutralisationRisk: circuit.neutralisationRisk ?? 1,
  }
}
```

```ts
/**
 * Circuits authored through docs/CIRCUIT-AUTHORING.md. The stricter geometry
 * and sensitivity rules in tests/data/circuitGeometry.test.ts bind these only;
 * the twelve legacy circuits predate them.
 */
export const V2_CIRCUITS: readonly string[] = []

/** Each sector's share of the loop's polyline length (boundaries are point indices). */
export function sectorArcShares(path: CircuitPath): [number, number, number] {
  const pts = path.points
  const seg: number[] = []
  for (let i = 1; i < pts.length; i++) {
    const a = pts[i - 1]!, b = pts[i]!
    seg.push(Math.hypot((b[0] ?? 0) - (a[0] ?? 0), (b[1] ?? 0) - (a[1] ?? 0)))
  }
  const [b1, b2] = [path.sectorBoundaries[0] ?? 0, path.sectorBoundaries[1] ?? 0]
  const sum = (from: number, to: number) => seg.slice(from, to).reduce((x, y) => x + y, 0)
  const total = sum(0, seg.length)
  return [sum(0, b1) / total, sum(b1, b2) / total, sum(b2, seg.length) / total]
}
```

```tsx
import { loadGameData } from '@data/validators'
import { circuitTraits } from '@engine/circuitTraits'
import { Pill } from './Pill'

export type TraitId = 'night' | 'street' | 'high_wear' | 'sc_risk'
const GAME = loadGameData()
const META: Record<TraitId, { text: string; label: string; tone: 'dusk' | 'hot' | 'caution' }> = {
  night: { text: 'NIGHT RACE', label: 'Night race', tone: 'dusk' },
  street: { text: 'STREET', label: 'Street circuit', tone: 'dusk' },
  high_wear: { text: 'HIGH WEAR', label: 'High tyre wear', tone: 'hot' },
  sc_risk: { text: 'SAFETY CAR RISK', label: 'High safety car risk', tone: 'caution' },
}

/** Spec 2026-10-24 §1.7: thresholds are presentation, so they live here, not in tuning. */
export function circuitTraitIds(circuitId: string): TraitId[] {
  const c = GAME.circuits[circuitId]
  if (!c) return []
  // Raw tyreWear, not circuitTraits().wear: the night discount must not hide HIGH WEAR.
  const t = circuitTraits(c, GAME.tuning)
  const out: TraitId[] = []
  if (c.timeOfDay === 'night') out.push('night')
  if (c.layout === 'street') out.push('street')
  if ((c.tyreWear ?? 1) >= 1.15) out.push('high_wear')
  if (t.crashRisk >= 1.3 || t.neutralisationRisk >= 1.3) out.push('sc_risk')
  return out
}

export function TraitPills({ circuitId }: { circuitId: string }) {
  const ids = circuitTraitIds(circuitId)
  if (ids.length === 0) return null
  return (
    <>
      {ids.map(id => <Pill key={id} tone={META[id].tone} ariaLabel={META[id].label}>{META[id].text}</Pill>)}
    </>
  )
}
```

```ts
/**
 * Where a night circuit's floodlight pools sit, as fractions of the lap
 * (spec 2026-10-24 §2.3). One pool per ~110 px of track, 6-10 pools, evenly
 * spaced from a fixed offset so the layout is stable across resizes. Pure.
 */
export function floodlightPoints(arcLength: number, count: number): number[] {
  const n = Math.max(6, Math.min(10, Math.round(Math.max(count, arcLength / 110))))
  return Array.from({ length: n }, (_, i) => (0.04 + i / n) % 1)
}
```

```ts
import { loadGameData } from '@data/validators'

/** FNV-1a 32-bit over UTF-16 code units (equal to the byte form for ASCII). Unsigned. */
export function fnv1a(text: string): number {
  let h = 0x811c9dc5
  for (let i = 0; i < text.length; i++) { h ^= text.charCodeAt(i); h = Math.imul(h, 0x01000193) }
  return h >>> 0
}

export function fnv1aBytes(bytes: Uint8Array): number {
  let h = 0x811c9dc5
  for (let i = 0; i < bytes.length; i++) { h ^= bytes[i]!; h = Math.imul(h, 0x01000193) }
  return h >>> 0
}

let cached: number | null = null
/**
 * A fingerprint of everything that decides a race: tuning (minus the test-only
 * bands), compounds, circuits, cars, drivers, strategies, upgrades. Two builds
 * with the same fingerprint race identically. Used to warn on drifted share
 * codes and to key daily bests (spec 2026-10-24 R18, R23).
 */
export function gameDataFingerprint(): number {
  if (cached !== null) return cached
  const d = loadGameData()
  const { _regressionBands: _b, ...tuning } = d.tuning
  cached = fnv1a(JSON.stringify({ tuning, compounds: d.compounds, circuits: d.circuits, cars: d.cars, drivers: d.drivers, strategies: d.strategies, upgrades: d.upgrades }))
  return cached
}
```

```ts
import { neutralisationKind } from '@engine/incidents'

import type { RaceState } from '@engine/types'
import { loadGameData } from '@data/validators'
import { buildScenarioConfig } from './buildRaceConfig'
import { PICKABLE_CIRCUITS } from './raceStore'
import { fnv1a } from './fingerprint'
import type { ActiveChallenge } from './scenarioStore'

export type DailyArchetype = 'recovery' | 'defend' | 'safety_car' | 'rain' | 'cliff' | 'open'
const ARCHETYPES: readonly DailyArchetype[] = ['recovery', 'defend', 'safety_car', 'rain', 'cliff', 'open']
const AUTOPILOT = '__none__'
const GAME = loadGameData()

export interface DailyChallenge {
  dateKey: string
  spec: ActiveChallenge
  archetype: DailyArchetype
  /** circuit:seed:lap:driver -- a best recorded under another signature is a different challenge (R18). */
  signature: string
  /** 0 = its archetype, 1 = open, 2 = last resort. Tests assert 2 never happens. */
  tier: 0 | 1 | 2
  racesRun: number
}

/** The device's local calendar date, 'YYYY-MM-DD' (ruling R15). */
export function dateKey(d: Date): string {
  const p = (n: number) => String(n).padStart(2, '0')
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`
}

export function dailyHash(key: string): number {
  return fnv1a(`daily:v${GAME.tuning.daily.rulesVersion}:${key}`)
}

function cliffFrac(circuitId: string, car: RaceState['cars'][number]): number {
  const wear = circuitTraits(GAME.circuits[circuitId]!, GAME.tuning).wear
  return (car.tyreAge * wear) / (GAME.compounds[car.compound]?.cliff ?? 1)
}

function matches(a: DailyArchetype, sit: ScenarioSituation, st: RaceState, car: RaceState['cars'][number], circuitId: string): boolean {
  switch (a) {
    case 'recovery': return sit.position >= 8 && car.tyreAge <= 5
    case 'defend': return sit.position <= 4 && cliffFrac(circuitId, car) >= 0.6
    case 'safety_car': { const k = neutralisationKind(st.safetyCar); return k === 'sc' || k === 'vsc' }
    case 'rain': return ['S', 'M', 'H'].includes(car.compound) && st.weatherTimeline[st.lap] === 'DRY'
      && st.weatherTimeline.slice(st.lap + 1, st.lap + 4).some(w => w !== 'DRY')
    case 'cliff': return cliffFrac(circuitId, car) >= 0.8
    case 'open': return true
    default: { const never: never = a; return never }
  }
}

interface Hit { lap: number; sit: ScenarioSituation; par: number; vsc: boolean }

/** One autopilot race: the first matching lap in the window, and par (the find-scenarios rule). */
function scan(circuitId: string, seed: number, driverId: string, a: DailyArchetype, range: readonly [number, number]): Hit | null {
  const config = buildScenarioConfig({ circuitId, seed, playerDriverId: AUTOPILOT })
  const laps = config.circuit.laps
  const [w0, w1] = GAME.tuning.daily.lapWindow
  const from = Math.max(1, Math.floor(laps * w0)), to = Math.floor(laps * w1)
  const rng = createRng(seed)
  let state = initRace(config)
  let first: Omit<Hit, 'par'> | null = null
  for (let lap = 1; lap <= laps; lap++) {
    for (let s = 0; s < 3; s++) state = stepSector(config, state, rng)
    if (first || lap < from || lap > to) continue
    const sit = describeSituation(state, driverId)
    const car = state.cars.find(c => c.driverId === driverId)
    if (!sit || !car || car.retired) continue
    if (sit.position < range[0] || sit.position > range[1] || sit.lapsRemaining < 8) continue
    if (matches(a, sit, state, car, circuitId)) first = { lap, sit, vsc: neutralisationKind(state.safetyCar) === 'vsc' }
  }
  const car = state.cars.find(c => c.driverId === driverId)
  if (!first || !car || car.retired || car.position < 2) return null
  return { ...first, par: car.position }
}

const BLURB: Record<DailyArchetype, (s: ScenarioSituation) => string> = {
  recovery: s => `P${s.position} on fresh tyres with ${s.lapsRemaining} laps to go. Carve back through.`,
  defend: s => `P${s.position}, tyres past their best, ${s.lapsRemaining} laps left. Hold it or stop and fight.`,
  safety_car: s => `The field is neutralised and you are P${s.position}. Cheap stop, or track position?`,
  rain: s => `Dry for now, rain is close, and you are P${s.position} on slicks. Call it.`,
  cliff: s => `P${s.position} and your tyres are at the cliff. ${s.lapsRemaining} laps is a long way.`,
  open: s => `P${s.position}, ${s.lapsRemaining} laps to go. Find the strategy that gains a place.`,
}

/** Today's challenge, deterministic from the date key (spec 2026-10-24 §4.2). */
export function generateDaily(key: string): DailyChallenge {
  const h = dailyHash(key)
  const stream = createRng(h)
  const pick = (n: number) => Math.floor(stream() * n)
  const circuitId = PICKABLE_CIRCUITS[h % PICKABLE_CIRCUITS.length]!
  const drivers = GAME.drivers.drivers
  const driverId = drivers[pick(drivers.length)]!.id
  const archetype = ARCHETYPES[pick(ARCHETYPES.length)]!
  const range = GAME.tuning.daily.positionRange
  const tiers: [DailyArchetype, readonly [number, number]][] = [[archetype, range], ['open', range], ['open', [2, 20]]]
  let racesRun = 0
  for (let t = 0; t < tiers.length; t++) {
    const [a, r] = tiers[t]!
    for (let k = 0; k < GAME.tuning.daily.maxSearchRaces; k++) {
      const seed = Math.floor(stream() * 2 ** 31)
      racesRun++
      const hit = scan(circuitId, seed, driverId, a, r)
      if (!hit) continue
      const circuit = GAME.circuits[circuitId]!
      const spec: ActiveChallenge = {
        kind: 'daily', id: `daily-${key}`, name: `Daily · ${circuit.name}`, blurb: BLURB[a](hit.sit),
        circuitId, seed, playerDriverId: driverId, startLap: hit.lap, goal: { position: hit.par - 1 },
        expect: {
          position: hit.sit.position, lapsRemaining: hit.sit.lapsRemaining, compound: hit.sit.compound,
          tyreAge: hit.sit.tyreAge, safetyCarOut: hit.sit.safetyCarOut, par: hit.par,
          ...(hit.vsc ? { vscOut: true as const } : {}),
        },
      }
      return { dateKey: key, spec, archetype: a, signature: `${circuitId}:${seed}:${hit.lap}:${driverId}`, tier: t as 0 | 1 | 2, racesRun }
    }
  }
  throw new Error(`daily ${key}: no challenge in ${racesRun} races`)   // tests/state/dailyYear.test.ts proves unreachable
}
```

```ts
import { create } from 'zustand'
import { z } from 'zod'
import { Preferences } from '@capacitor/preferences'
import { loadGameData } from '@data/validators'
import { generateDaily, dateKey, type DailyChallenge } from './daily'
import { betterBest, type ScenarioOutcome } from './scenarioStore'

export const DAILY_BEST_KEY = 'daily.best'
export interface DailyBest { signature: string; position: number | null; met: boolean }
const BestSchema = z.record(z.string(), z.object({ signature: z.string(), position: z.number().nullable(), met: z.boolean() }))

export function pruneBests(b: Record<string, DailyBest>, keep: number): Record<string, DailyBest> {
  return Object.fromEntries(Object.keys(b).sort().slice(-keep).map(k => [k, b[k]!]))
}

async function readBest(): Promise<Record<string, DailyBest>> {
  try {
    const { value } = await Preferences.get({ key: DAILY_BEST_KEY })
    const parsed = BestSchema.safeParse(value ? JSON.parse(value) : {})
    return parsed.success ? parsed.data : {}
  } catch { return {} }
}

let writeChain: Promise<void> = Promise.resolve()

interface DailyStore {
  today: DailyChallenge | null
  status: 'idle' | 'building' | 'ready' | 'failed'
  best: Record<string, DailyBest>
  build: (now?: Date) => void
  loadBest: () => Promise<void>
  record: (outcome: ScenarioOutcome) => void
  bestFor: (d: DailyChallenge) => DailyBest | null
}

/**
 * Today's challenge and a personal best per day. Nothing else: no streak, no
 * history view, no countdown, no reward (spec 2026-10-24 §4, R16).
 */
export const useDailyStore = create<DailyStore>((set, get) => ({
  today: null,
  status: 'idle',
  best: {},
  build(now = new Date()) {
    const key = dateKey(now)
    if (get().today?.dateKey === key && get().status === 'ready') return
    set({ status: 'building' })
    // Deferred so the tab paints its loader first (R17).
    setTimeout(() => {
      try { set({ today: generateDaily(key), status: 'ready' }) } catch { set({ status: 'failed' }) }
    }, 0)
  },
  async loadBest() { const stored = await readBest(); set(s => ({ best: { ...stored, ...s.best } })) },
  record(outcome) {
    const d = get().today
    if (!d) return
    const prev = get().bestFor(d) ?? undefined
    const merged = betterBest(prev, { position: outcome.retired ? null : outcome.position, met: outcome.met })
    const entry: DailyBest = { signature: d.signature, ...merged }
    set(s => ({ best: { ...s.best, [d.dateKey]: entry } }))
    writeChain = writeChain.then(async () => {
      try {
        const stored = await readBest()
        const next = pruneBests({ ...stored, [d.dateKey]: entry }, loadGameData().tuning.daily.keepDays)
        await Preferences.set({ key: DAILY_BEST_KEY, value: JSON.stringify(next) })
      } catch { /* best-effort; the in-memory best stands */ }
    })
  },
  bestFor(d) {
    const b = get().best[d.dateKey]
    return b && b.signature === d.signature ? b : null
  },
}))
```

```ts
import type { RaceConfig, CircuitSpec } from '@engine/index'
import type { Tuning } from '@data/validators'
import type { Difficulty } from './settingsStore'
import type { PlayerStrategyChoice } from './seasonStore'
import type { UpgradeOverlayInput } from './upgradeOverlay'
import { buildRaceConfig } from './buildRaceConfig'

export type LapsPercent = 25 | 50 | 75 | 100
export type WeatherMix = 'circuit' | 'dry' | 'changeable' | 'wet'

/**
 * Everything buildRaceConfig needs, as data (spec 2026-10-24 §5.2, R19). With
 * the seed and the player's calls it reproduces a race exactly; it is what a
 * custom start and its share code carry.
 */
export interface RaceRecipe {
  seed: number
  playerDriverId: string
  circuitId: string
  difficulty: Difficulty
  strategy: PlayerStrategyChoice | null
  overlay: UpgradeOverlayInput | null
  gridOrder: string[] | null
  dryStart: boolean
  sprint: boolean
  allDry: boolean
  lapsPercent: LapsPercent
  weather: WeatherMix
}

export function buildConfigFromRecipe(r: RaceRecipe): RaceConfig {
  return buildRaceConfig(r.seed, r.playerDriverId, r.circuitId, r.difficulty, r.strategy, r.overlay,
    r.gridOrder ?? undefined, r.dryStart, r.sprint, r.allDry, r.lapsPercent, r.weather)
}

/** The circuit as a weather mix races it. 'circuit' and 'dry' return the data object itself. */
export function weatherCircuit(c: CircuitSpec, mix: WeatherMix, t: Tuning): CircuitSpec {
  switch (mix) {
    case 'circuit': case 'dry': return c
    case 'changeable': {
      const w = t.custom.weather.changeable
      return { ...c, rainProbability: Math.min(w.rainMax, Math.max(w.rainMin, (c.rainProbability ?? 0) * w.rainScale)), weatherBias: w.bias }
    }
    case 'wet': return { ...c, rainProbability: t.custom.weather.wet.rainProbability, weatherBias: t.custom.weather.wet.bias }
    default: { const never: never = mix; return never }
  }
}
```

```ts
  return calls.filter(c => c.step < startLap * 3)
}

/**
 * A custom start's handover (spec 2026-10-24 §5.3): the race replayed with the
 * player's own calls up to the start of `startLap + 1`, and the LIVE rng --
 * continuing with a fresh one would fork the race. A plan hold left open (the
 * pit panel was up at the moment) is released; that draws nothing.
 */
export function handoverFromCalls(config: RaceConfig, calls: readonly PlayerCall[], startLap: number): { state: RaceState; rng: Rng } {
  const { state, rng } = replay(config, config.seed, prefixCalls(calls, startLap), startLap * 3)
  return { state: applyPlanHold(state, false), rng }
}

/** Par: where the player's car finishes when the AI drives it from the handover (the scenarios.test rule). */
export function parFromHandover(config: RaceConfig, calls: readonly PlayerCall[], startLap: number): { position: number; retired: boolean } {
  const { state, rng } = handoverFromCalls(config, calls, startLap)
  const auto: RaceConfig = { ...config, playerDriverId: AUTOPILOT }
  let s: RaceState = { ...state, cars: state.cars.map(c => ({ ...c, isPlayer: false })) }
  const total = (config.lapsOverride ?? config.circuit.laps) * 3
  for (let i = startLap * 3; i < total; i++) s = stepSector(auto, s, rng)
  const car = s.cars.find(c => c.driverId === config.playerDriverId)
  return { position: car?.position ?? s.cars.length, retired: car?.retired ?? true }
}
```

```ts
import { z } from 'zod'
import type { PlayerCall } from '@engine/playerCalls'
import type { Compound } from '@engine/types'
import { loadGameData } from '@data/validators'
import { fnv1aBytes } from './fingerprint'
import { buildConfigFromRecipe, type RaceRecipe, type LapsPercent, type WeatherMix } from './raceRecipe'
import {
  CIRCUIT_CODES, DRIVER_CODES, TEAM_CODES, COMPOUND_CODES, PACE_CODES, LAPS_PERCENTS, WEATHER_CODES, ATTRIBUTE_CODES, CALL_KINDS,
} from './startCodes'

export const CODE_FORMAT = 1
export const MAX_CODE_CHARS = 2048
const NAME_RE = /^[\x20-\x7E]{1,24}$/

export interface StartExpect { position: number; lapsRemaining: number; compound: Compound; tyreAge: number; par: number }
export interface StartPayload { fingerprint: number; recipe: RaceRecipe; calls: PlayerCall[]; startLap: number; expect: StartExpect; name: string }
export type DecodeResult = { ok: true; payload: StartPayload; id: string } | { ok: false; reason: 'format' | 'checksum' | 'newer' | 'invalid' }

// ---- bytes -----------------------------------------------------------------

class Writer {
  private out: number[] = []
  u8(v: number) { if (!Number.isInteger(v) || v < 0 || v > 255) throw new RangeError(`u8 ${v}`); this.out.push(v) }
  i8(v: number) { if (!Number.isInteger(v) || v < -128 || v > 127) throw new RangeError(`i8 ${v}`); this.out.push(v & 0xff) }
  u16(v: number) { if (!Number.isInteger(v) || v < 0 || v > 0xffff) throw new RangeError(`u16 ${v}`); this.out.push(v >>> 8, v & 0xff) }
  u32(v: number) { if (!Number.isInteger(v) || v < 0 || v > 0xffffffff) throw new RangeError(`u32 ${v}`); this.out.push(v >>> 24, (v >>> 16) & 0xff, (v >>> 8) & 0xff, v & 0xff) }
  f64(v: number) { const b = new DataView(new ArrayBuffer(8)); b.setFloat64(0, v); for (let i = 0; i < 8; i++) this.out.push(b.getUint8(i)) }
  bytes(): Uint8Array { return Uint8Array.from(this.out) }
}

class Reader {
  private pos = 0
  constructor(private readonly b: Uint8Array) {}
  private need(n: number) { if (this.pos + n > this.b.length) throw new RangeError('short') }
  u8() { this.need(1); return this.b[this.pos++]! }
  i8() { const v = this.u8(); return v > 127 ? v - 256 : v }
  u16() { return (this.u8() << 8) | this.u8() }
  u32() { return ((this.u8() << 24) | (this.u8() << 16) | (this.u8() << 8) | this.u8()) >>> 0 }
  f64() { this.need(8); const v = new DataView(this.b.buffer, this.b.byteOffset + this.pos, 8).getFloat64(0); this.pos += 8; return v }
  done() { return this.pos === this.b.length }
}

function b64url(bytes: Uint8Array): string {
  let s = ''
  for (const x of bytes) s += String.fromCharCode(x)
  return btoa(s).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '')
}
function unb64url(text: string): Uint8Array | null {
  if (!/^[A-Za-z0-9_-]*$/.test(text) || text.length % 4 === 1) return null
  try {
    const bin = atob(text.replace(/-/g, '+').replace(/_/g, '/') + '='.repeat((4 - (text.length % 4)) % 4))
    return Uint8Array.from(bin, ch => ch.charCodeAt(0))
  } catch { return null }
}

function idx<T extends string | number>(table: readonly T[], v: T): number {
  const i = table.indexOf(v)
  if (i < 0) throw new RangeError(`not in table: ${String(v)}`)
  return i
}
function at<T>(table: readonly T[], i: number): T {
  const v = table[i]
  if (v === undefined) throw new RangeError(`index ${i}`)
  return v
}

// ---- encode ----------------------------------------------------------------

/** Throws on a payload that cannot be represented (programmer error, never user input). */
export function encodeStart(p: StartPayload): string {
  if (!NAME_RE.test(p.name)) throw new RangeError('name must be 1-24 printable ASCII characters')
  const r = p.recipe
  const w = new Writer()
  w.u8(CODE_FORMAT); w.u32(p.fingerprint >>> 0); w.u32(r.seed >>> 0)
  w.u8(idx(CIRCUIT_CODES, r.circuitId as (typeof CIRCUIT_CODES)[number]))
  w.u8(idx(DRIVER_CODES, r.playerDriverId as (typeof DRIVER_CODES)[number]))
  w.u8(p.startLap)
  w.u8((r.sprint ? 1 : 0) | (r.dryStart ? 2 : 0) | (r.allDry ? 4 : 0) | (r.difficulty === 'pro' ? 8 : 0)
    | (r.strategy ? 16 : 0) | (r.gridOrder ? 32 : 0) | (r.overlay ? 64 : 0))
  w.u8(r.lapsPercent); w.u8(idx(WEATHER_CODES, r.weather))
  if (r.strategy) {
    w.u8(idx(COMPOUND_CODES, r.strategy.startCompound)); w.u8(r.strategy.wing ?? 0); w.u8(r.strategy.plannedStops.length)
    for (const s of r.strategy.plannedStops) { w.u8(s.lap); w.u8(idx(COMPOUND_CODES, s.compound)) }
  }
  if (r.gridOrder) { w.u8(r.gridOrder.length); for (const id of r.gridOrder) w.u8(idx(DRIVER_CODES, id as (typeof DRIVER_CODES)[number])) }
  if (r.overlay) {
    let packed = 0
    ATTRIBUTE_CODES.forEach((a, i) => { packed |= ((r.overlay!.purchasedTiers[a] ?? 0) & 3) << (2 * i) })
    w.u16(packed)
    const rival = Object.entries(r.overlay.rivalDevelopment ?? {})
    w.u8(rival.length); for (const [t, v] of rival) { w.u8(idx(TEAM_CODES, t as (typeof TEAM_CODES)[number])); w.f64(v) }
    const tiers = Object.entries(r.overlay.teamTiers ?? {})
    w.u8(tiers.length); for (const [t, v] of tiers) { w.u8(idx(TEAM_CODES, t as (typeof TEAM_CODES)[number])); w.i8(v) }
  }
  w.u8(p.calls.length)
  for (const c of p.calls) {
    w.u16(c.step); w.u8(idx(CALL_KINDS, c.kind))
    switch (c.kind) {
      case 'pit': case 'restart_tyre': w.u8(idx(COMPOUND_CODES, c.compound)); break
      case 'pace': w.u8(idx(PACE_CODES, c.mode)); break
      case 'hold_plan': w.u8(c.hold ? 1 : 0); break
      default: { const never: never = c; throw new RangeError(String(never)) }
    }
  }
  const e = p.expect
  w.u8(e.position); w.u8(e.lapsRemaining); w.u8(idx(COMPOUND_CODES, e.compound)); w.u8(e.tyreAge); w.u8(e.par)
  w.u8(p.name.length); for (const ch of p.name) w.u8(ch.charCodeAt(0))
  const body = w.bytes()
  const sum = fnv1aBytes(body)
  const all = new Uint8Array(body.length + 4)
  all.set(body); all.set([sum >>> 24, (sum >>> 16) & 0xff, (sum >>> 8) & 0xff, sum & 0xff], body.length)
  return `PW${CODE_FORMAT}-${b64url(all)}`
}

// ---- decode ----------------------------------------------------------------

const PayloadSchema = z.object({
  fingerprint: z.number().int().min(0).max(0xffffffff),
  startLap: z.number().int().min(1).max(255),
  name: z.string().regex(NAME_RE),
  expect: z.object({ position: z.number().int().min(1).max(40), lapsRemaining: z.number().int().min(1), compound: z.enum(COMPOUND_CODES), tyreAge: z.number().int().min(0), par: z.number().int().min(1).max(40) }),
  calls: z.array(z.unknown()).max(255),
  recipe: z.object({ lapsPercent: z.union([z.literal(25), z.literal(50), z.literal(75), z.literal(100)]) }).passthrough(),
})

function read(bytes: Uint8Array): StartPayload {
  const r = new Reader(bytes)
  r.u8()   // format, checked by the caller
  const fingerprint = r.u32(), seed = r.u32()
  const circuitId = at(CIRCUIT_CODES, r.u8()), playerDriverId = at(DRIVER_CODES, r.u8())
  const startLap = r.u8(), flags = r.u8()
  if (flags & 128) throw new RangeError('flags')
  const lapsPercent = r.u8() as LapsPercent
  if (!(LAPS_PERCENTS as readonly number[]).includes(lapsPercent)) throw new RangeError('laps')
  const weather: WeatherMix = at(WEATHER_CODES, r.u8())
  let strategy: RaceRecipe['strategy'] = null
  if (flags & 16) {
    const startCompound = at(COMPOUND_CODES, r.u8()), wing = r.u8(), n = r.u8()
    if (wing > 5 || n > 2) throw new RangeError('strategy')
    const plannedStops = Array.from({ length: n }, () => ({ lap: r.u8(), compound: at(COMPOUND_CODES, r.u8()) }))
    strategy = { startCompound, plannedStops, ...(wing ? { wing: wing as 1 | 2 | 3 | 4 | 5 } : {}) }
  }
  let gridOrder: string[] | null = null
  if (flags & 32) { const n = r.u8(); gridOrder = Array.from({ length: n }, () => at(DRIVER_CODES, r.u8())) }
  let overlay: RaceRecipe['overlay'] = null
  if (flags & 64) {
    const packed = r.u16()
    const purchasedTiers: Record<string, number> = {}
    ATTRIBUTE_CODES.forEach((a, i) => { const t = (packed >>> (2 * i)) & 3; if (t) purchasedTiers[a] = t })
    if (packed >>> 10) throw new RangeError('tiers')
    const rivalDevelopment: Record<string, number> = {}
    for (let n = r.u8(); n > 0; n--) { const t = at(TEAM_CODES, r.u8()); if (t in rivalDevelopment) throw new RangeError('dup'); rivalDevelopment[t] = r.f64() }
    const teamTiers: Record<string, number> = {}
    for (let n = r.u8(); n > 0; n--) { const t = at(TEAM_CODES, r.u8()); if (t in teamTiers) throw new RangeError('dup'); teamTiers[t] = r.i8() }
    overlay = { purchasedTiers, rivalDevelopment, teamTiers }
  }
  const calls: PlayerCall[] = []
  for (let n = r.u8(); n > 0; n--) {
    const step = r.u16(), kind = at(CALL_KINDS, r.u8()), arg = r.u8()
    switch (kind) {
      case 'pit': calls.push({ step, kind, compound: at(COMPOUND_CODES, arg) }); break
      case 'restart_tyre': calls.push({ step, kind, compound: at(COMPOUND_CODES, arg) }); break
      case 'pace': calls.push({ step, kind, mode: at(PACE_CODES, arg) }); break
      case 'hold_plan': if (arg > 1) throw new RangeError('hold'); calls.push({ step, kind, hold: arg === 1 }); break
      default: { const never: never = kind; throw new RangeError(String(never)) }
    }
  }
  const expect: StartExpect = { position: r.u8(), lapsRemaining: r.u8(), compound: at(COMPOUND_CODES, r.u8()), tyreAge: r.u8(), par: r.u8() }
  let name = ''
  for (let n = r.u8(); n > 0; n--) name += String.fromCharCode(r.u8())
  if (!r.done()) throw new RangeError('trailing bytes')
  const recipe: RaceRecipe = {
    seed, playerDriverId, circuitId, difficulty: flags & 8 ? 'pro' : 'rookie', strategy, overlay, gridOrder,
    dryStart: !!(flags & 2), sprint: !!(flags & 1), allDry: !!(flags & 4), lapsPercent, weather,
  }
  return { fingerprint, recipe, calls, startLap, expect, name }
}

/** The semantic rules (spec §5.4): a code may only describe a race this build can run. */
export function validatePayload(p: StartPayload): boolean {
  if (!PayloadSchema.safeParse(p).success) return false
  const data = loadGameData()
  const r = p.recipe
  if (!data.circuits[r.circuitId] || !data.drivers.drivers.some(d => d.id === r.playerDriverId)) return false
  let laps: number
  try { const c = buildConfigFromRecipe(r); laps = c.lapsOverride ?? c.circuit.laps } catch { return false }
  if (p.startLap > laps - 3) return false
  let prev = 0
  for (const c of p.calls) { if (c.step < prev || c.step >= p.startLap * 3) return false; prev = c.step }
  if (r.gridOrder) {
    const all = data.drivers.drivers.map(d => d.id)
    if (r.gridOrder.length !== all.length || new Set(r.gridOrder).size !== all.length || !all.every(id => r.gridOrder!.includes(id))) return false
  }
  if (r.strategy) {
    let last = 0
    for (const s of r.strategy.plannedStops) { if (s.lap <= last || s.lap >= laps) return false; last = s.lap }
  }
  if (r.overlay) {
    const { min, max } = data.tuning.career.teamTiers
    for (const v of Object.values(r.overlay.rivalDevelopment ?? {})) if (!Number.isFinite(v) || v < 0 || v > 200) return false
    for (const v of Object.values(r.overlay.teamTiers ?? {})) if (v < min || v > max) return false
  }
  return p.expect.par <= data.drivers.drivers.length && p.expect.position <= data.drivers.drivers.length
}

/** Never throws (spec §5.4). Whitespace anywhere is ignored. */
export function decodeStart(text: string): DecodeResult {
  try {
    if (typeof text !== 'string' || text.length > MAX_CODE_CHARS) return { ok: false, reason: 'format' }
    const t = text.replace(/\s+/g, '')
    const m = /^PW(\d{1,3})-(.*)$/.exec(t)
    if (!m) return { ok: false, reason: 'format' }
    const version = Number(m[1])
    if (version > CODE_FORMAT) return { ok: false, reason: 'newer' }
    if (version !== CODE_FORMAT) return { ok: false, reason: 'format' }
    const all = unb64url(m[2] ?? '')
    if (!all || all.length < 6) return { ok: false, reason: 'format' }
    const body = all.subarray(0, all.length - 4)
    const sum = ((all[all.length - 4]! << 24) | (all[all.length - 3]! << 16) | (all[all.length - 2]! << 8) | all[all.length - 1]!) >>> 0
    if (fnv1aBytes(body) !== sum) return { ok: false, reason: 'checksum' }
    if (body[0]! > CODE_FORMAT) return { ok: false, reason: 'newer' }
    if (body[0]! !== CODE_FORMAT) return { ok: false, reason: 'format' }
    let payload: StartPayload
    try { payload = read(body) } catch { return { ok: false, reason: 'format' } }
    if (!validatePayload(payload)) return { ok: false, reason: 'invalid' }
    return { ok: true, payload, id: sum.toString(16).padStart(8, '0') }
  } catch {
    return { ok: false, reason: 'format' }
  }
}
```

Notes for the implementer: `'PW1-AAAA'` decodes to 3 bytes, under the 6-byte minimum → `format`; the "every single-character mutation" test can in principle collide with the 32-bit checksum (≈ 1 in 4 × 10⁹ per mutation); it is deterministic, so a pass is a pass forever. A mutation in the final base64 character can change only padding bits — if the test reports such a position decoding *successfully to the same payload*, skip the last character in that loop (`i < code.length - 1`) and say so in the commit; that is base64, not the codec.

```ts
import { handoverFromCalls, parFromHandover, prefixCalls } from '@engine/customStart'
import { describeSituation, type ScenarioSituation } from '@engine/scenario'
import type { Compound } from '@engine/types'
import { loadGameData } from '@data/validators'
import { buildConfigFromRecipe, type RaceRecipe } from './raceRecipe'
import { gameDataFingerprint } from './fingerprint'
import type { StartPayload } from './startCode'
import type { ActiveChallenge } from './scenarioStore'

export type MakeStartResult = { ok: true; payload: StartPayload } | { ok: false; reason: 'lap_range' | 'par_one' | 'par_retired' }

export function lapRange(recipe: RaceRecipe): { min: number; max: number } {
  const c = buildConfigFromRecipe(recipe)
  return { min: 1, max: (c.lapsOverride ?? c.circuit.laps) - 3 }
}

export function situationAt(recipe: RaceRecipe, calls: readonly PlayerCall[], lap: number): ScenarioSituation | null {
  const { state } = handoverFromCalls(buildConfigFromRecipe(recipe), calls, lap)
  return describeSituation(state, recipe.playerDriverId)
}

export function defaultStartName(circuitId: string, lap: number): string {
  const name = (loadGameData().circuits[circuitId]?.name ?? circuitId).replace(/\s+GP$/, '').toUpperCase().replace(/[^\x20-\x7E]/g, '')
  const suffix = ` L${lap}`
  return name.slice(0, 24 - suffix.length) + suffix
}

/** Spec 2026-10-24 §5.1, R21: goal = par - 1; par P1 or a retired par refuses the lap. */
export function makeCustomStart(recipe: RaceRecipe, calls: readonly PlayerCall[], lap: number, name?: string): MakeStartResult {
  const range = lapRange(recipe)
  if (!Number.isInteger(lap) || lap < range.min || lap > range.max) return { ok: false, reason: 'lap_range' }
  const config = buildConfigFromRecipe(recipe)
  const par = parFromHandover(config, calls, lap)
  if (par.retired) return { ok: false, reason: 'par_retired' }
  if (par.position <= 1) return { ok: false, reason: 'par_one' }
  const sit = situationAt(recipe, calls, lap)!
  return {
    ok: true,
    payload: {
      fingerprint: gameDataFingerprint(), recipe, calls: prefixCalls(calls, lap), startLap: lap,
      expect: { position: sit.position, lapsRemaining: sit.lapsRemaining, compound: sit.compound as Compound, tyreAge: sit.tyreAge, par: par.position },
      name: name ?? defaultStartName(recipe.circuitId, lap),
    },
  }
}

export interface Rederived { situation: ScenarioSituation; par: number; parRetired: boolean; drift: boolean }

/** The start as THIS build plays it, and whether that differs from what the code promised (R23). */
export function rederive(p: StartPayload): Rederived | null {
  const situation = situationAt(p.recipe, p.calls, p.startLap)
  if (!situation) return null
  const par = parFromHandover(buildConfigFromRecipe(p.recipe), p.calls, p.startLap)
  const e = p.expect
  const drift = situation.position !== e.position || situation.lapsRemaining !== e.lapsRemaining
    || situation.compound !== e.compound || situation.tyreAge !== e.tyreAge || par.position !== e.par || par.retired
  return { situation, par: par.position, parRetired: par.retired, drift }
}

export function startChallenge(id: string, p: StartPayload, r: Rederived): ActiveChallenge {
  const circuit = loadGameData().circuits[p.recipe.circuitId]
  return {
    kind: 'start', id: `start-${id}`, name: p.name,
    blurb: `${circuit?.name ?? p.recipe.circuitId}, lap ${p.startLap}. P${r.situation.position} with ${r.situation.lapsRemaining} laps to go.`,
    circuitId: p.recipe.circuitId, seed: p.recipe.seed, playerDriverId: p.recipe.playerDriverId, startLap: p.startLap,
    sprint: p.recipe.sprint || undefined,
    goal: { position: Math.max(1, r.par - 1) },
    expect: { position: r.situation.position, lapsRemaining: r.situation.lapsRemaining, compound: r.situation.compound, tyreAge: r.situation.tyreAge, safetyCarOut: r.situation.safetyCarOut, par: r.par },
    recipe: p.recipe, calls: p.calls,
  }
}
```

```ts
import { create } from 'zustand'
import { z } from 'zod'
import { Preferences } from '@capacitor/preferences'
import { decodeStart, encodeStart, type StartPayload } from './startCode'
import { rederive } from './customStart'
import { betterBest, type ScenarioBest, type ScenarioOutcome } from './scenarioStore'

export const STARTS_KEY = 'starts.mine'
export const MAX_STARTS = 30
export interface SavedStart { id: string; code: string; savedAt: number; best: ScenarioBest | null }
const FileSchema = z.object({
  v: z.literal(1),
  starts: z.array(z.object({ id: z.string(), code: z.string(), savedAt: z.number(), best: z.object({ position: z.number().nullable(), met: z.boolean() }).nullable() })),
})

/** Same start = same race, same calls, same lap; the name does not count. */
function sameStart(a: StartPayload, b: StartPayload): boolean {
  return JSON.stringify([a.recipe, a.calls, a.startLap]) === JSON.stringify([b.recipe, b.calls, b.startLap])
}
function payloadOf(s: SavedStart): StartPayload | null { const d = decodeStart(s.code); return d.ok ? d.payload : null }

let writeChain: Promise<void> = Promise.resolve()
function persist(starts: SavedStart[]) {
  writeChain = writeChain.then(async () => {
    try { await Preferences.set({ key: STARTS_KEY, value: JSON.stringify({ v: 1, starts }) }) } catch { /* best-effort */ }
  })
}

type ImportResult = { ok: true; id: string; drift: boolean } | { ok: false; reason: 'format' | 'checksum' | 'newer' | 'invalid' | 'unplayable' }
interface StartsStore {
  starts: SavedStart[]
  load: () => Promise<void>
  save: (p: StartPayload, now?: number) => { id: string; full: boolean }
  importCode: (text: string, now?: number) => ImportResult
  rename: (id: string, name: string) => void
  remove: (id: string) => void
  recordBest: (id: string, o: ScenarioOutcome) => void
}

export const useStartsStore = create<StartsStore>((set, get) => ({
  starts: [],
  async load() {
    try {
      const { value } = await Preferences.get({ key: STARTS_KEY })
      const parsed = FileSchema.safeParse(value ? JSON.parse(value) : { v: 1, starts: [] })
      set({ starts: parsed.success ? parsed.data.starts.filter(s => decodeStart(s.code).ok) : [] })
    } catch { set({ starts: [] }) }
  },
  save(p, now = Date.now()) {
    const existing = get().starts.find(s => { const q = payloadOf(s); return q !== null && sameStart(q, p) })
    if (existing) return { id: existing.id, full: false }
    const code = encodeStart(p)
    const d = decodeStart(code)
    const id = d.ok ? d.id : code.slice(-8)
    const full = get().starts.length >= MAX_STARTS
    const starts = [{ id, code, savedAt: now, best: null }, ...get().starts].slice(0, MAX_STARTS)
    set({ starts }); persist(starts)
    return { id, full }
  },
  importCode(text, now = Date.now()) {
    const d = decodeStart(text)
    if (!d.ok) return { ok: false, reason: d.reason }
    const r = rederive(d.payload)
    if (!r || r.parRetired || r.par <= 1) return { ok: false, reason: 'unplayable' }
    return { ok: true, id: get().save(d.payload, now).id, drift: r.drift }
  },
  rename(id, name) {
    const starts = get().starts.map(s => {
      const p = s.id === id ? payloadOf(s) : null
      return p ? { ...s, code: encodeStart({ ...p, name }) } : s
    })
    set({ starts }); persist(starts)
  },
  remove(id) { const starts = get().starts.filter(s => s.id !== id); set({ starts }); persist(starts) },
  recordBest(id, o) {
    const entry: ScenarioBest = { position: o.retired ? null : o.position, met: o.met }
    const starts = get().starts.map(s => s.id === id ? { ...s, best: betterBest(s.best ?? undefined, entry) } : s)
    set({ starts }); persist(starts)
  },
}))
```

```ts
import { loadGameData } from '@data/validators'
import type { Difficulty } from './settingsStore'
import type { LapsPercent, WeatherMix } from './raceRecipe'
import type { RaceKind } from './seasonStore'
import { CIRCUIT_ORDER } from './raceStore'
import { fnv1a } from './fingerprint'

export type SeasonSlot = 'career' | 'custom'
export type SprintDensity = 'none' | 'few' | 'many'

/** What a championship is (spec 2026-10-24 §6.2). The career is one fixed rule set. */
export interface SeasonRules {
  slot: SeasonSlot
  calendar: readonly string[]
  lapsPercent: LapsPercent
  /** null = follow Settings (the career). */
  difficulty: Difficulty | null
  weather: WeatherMix
  /** 1-based rounds. */
  sprints: readonly number[]
  /** Custom only; the career seeds through seedFor(). */
  seedBase: number
  championshipNumber: number
}

const T = loadGameData().tuning
export const CAREER_RULES: SeasonRules = Object.freeze({
  slot: 'career', calendar: CIRCUIT_ORDER, lapsPercent: 100, difficulty: null, weather: 'circuit',
  sprints: T.sprint.rounds, seedBase: 0, championshipNumber: 1,
})

export const roundsOf = (r: SeasonRules): number => r.calendar.length
export const circuitForRound = (r: SeasonRules, raceIndex: number): string => r.calendar[raceIndex % r.calendar.length] ?? r.calendar[0]!
export const isSprintRoundIn = (r: SeasonRules, raceIndex: number): boolean => r.sprints.includes(raceIndex + 1)

export function sprintRoundsFor(density: SprintDensity, rounds: number): number[] {
  if (density === 'none') return []
  const every = T.custom.sprintEvery[density]
  const out: number[] = []
  for (let r = every; r <= rounds; r += every) out.push(r)
  return out
}

/**
 * Custom seeds live at or above 2^31; career seeds, (season-1)*1e5 + ..., stay
 * below it for 21,000 seasons -- so the two can never collide (pinned).
 */
export function customSeedFor(r: SeasonRules, raceIndex: number, attemptNonce: number, kind: RaceKind): number {
  return r.seedBase + raceIndex * 1000 + 42 + attemptNonce * 7919 + (kind === 'sprint' ? T.sprint.seedSalt : 0)
}

export function newCustomSeedBase(rulesJson: string, createdAt: number): number {
  return 2 ** 31 + (fnv1a(`${rulesJson}:${createdAt}`) & 0x7ff) * 1_000_000
}
```

```ts
import { z } from 'zod'
import { Preferences } from '@capacitor/preferences'
import { migrateSave, type MigrationRegistry } from './saveMigration'
import { SeasonSnapshotSchema, snapshotFrom } from './seasonPersistence'
import { useSeasonStore } from './seasonStore'

/** Its own key and version (spec 2026-10-24 §6.2): no custom bug can cost a career. */
export const CUSTOM_SAVE_KEY = 'custom.save'
export const CUSTOM_SAVE_VERSION = 1
export const CUSTOM_MIGRATIONS: MigrationRegistry = {}

export const CustomRulesSchema = z.object({
  slot: z.literal('custom'),
  calendar: z.array(z.string()).min(2).max(14),
  lapsPercent: z.union([z.literal(25), z.literal(50), z.literal(75), z.literal(100)]),
  difficulty: z.enum(['rookie', 'pro']),
  weather: z.enum(['circuit', 'dry', 'changeable', 'wet']),
  sprints: z.array(z.number().int().min(2)),
  seedBase: z.number().int().min(0).max(0xffffffff),
  championshipNumber: z.number().int().min(1),
})

export const CustomSnapshotSchema = SeasonSnapshotSchema.omit({ v: true }).extend({
  v: z.literal(CUSTOM_SAVE_VERSION),
  rules: CustomRulesSchema,
  titles: z.number().int().min(0),
  championshipsRun: z.number().int().min(1),
})
export type CustomSnapshot = z.infer<typeof CustomSnapshotSchema>
type SeasonState = ReturnType<typeof useSeasonStore.getState>

export function customSnapshotFrom(s: SeasonState): CustomSnapshot | null {
  if (s.rules.slot !== 'custom') return null
  const base = snapshotFrom(s)
  if (!base) return null
  const { v: _v, ...rest } = base
  return {
    ...rest, v: CUSTOM_SAVE_VERSION,
    rules: { ...s.rules, slot: 'custom', calendar: [...s.rules.calendar], sprints: [...s.rules.sprints], difficulty: s.rules.difficulty ?? 'rookie' },
    titles: s.customTally.titles, championshipsRun: s.customTally.championshipsRun,
  }
}

export async function saveCustom(snap: CustomSnapshot): Promise<void> { await Preferences.set({ key: CUSTOM_SAVE_KEY, value: JSON.stringify(snap) }) }
export async function clearCustom(): Promise<void> { await Preferences.remove({ key: CUSTOM_SAVE_KEY }) }

export async function loadCustom(): Promise<CustomSnapshot | null> {
  try {
    const { value } = await Preferences.get({ key: CUSTOM_SAVE_KEY })
    if (!value) return null
    const migrated = migrateSave(JSON.parse(value), CUSTOM_SAVE_VERSION, CUSTOM_MIGRATIONS)
    if (!migrated.data) return null
    const parsed = CustomSnapshotSchema.safeParse(migrated.data)
    return parsed.success ? parsed.data : null
  } catch { return null }
}

/** The custom twin of startSeasonAutosave: derived, never remembered. */
export function startCustomAutosave(): () => void {
  let last: string | null = null
  return useSeasonStore.subscribe(state => {
    if (state.rules.slot !== 'custom') return
    const snap = customSnapshotFrom(state)
    if (!snap) {
      if (!state.playerDriverId && last !== null) { last = null; void clearCustom() }
      return
    }
    const serialised = JSON.stringify(snap)
    if (serialised === last) return
    last = serialised
    void saveCustom(snap)
  })
}
```

```ts
export function resolvedTheme(theme: Theme, prefersLight: boolean): 'night' | 'day' {
  return theme === 'system' ? (prefersLight ? 'day' : 'night') : theme
}

function osPrefersLight(): boolean {
  return typeof window !== 'undefined' && typeof window.matchMedia === 'function' && window.matchMedia('(prefers-color-scheme: light)').matches
}

export function applyDisplaySettings(root: HTMLElement, s: Pick<SettingsState, 'tyrePalette' | 'textSize' | 'theme'>, prefersLight = osPrefersLight()): void {
  // ...existing palette and text-size lines...
  if (resolvedTheme(s.theme, prefersLight) === 'day') root.setAttribute('data-theme', 'day')
  else root.removeAttribute('data-theme')
}

export function startDisplaySettingsSync(root: HTMLElement = document.documentElement): () => void {
  applyDisplaySettings(root, useSettingsStore.getState())
  const unsub = useSettingsStore.subscribe(s => applyDisplaySettings(root, s))
  const mq = typeof window !== 'undefined' && typeof window.matchMedia === 'function' ? window.matchMedia('(prefers-color-scheme: light)') : null
  const onChange = () => applyDisplaySettings(root, useSettingsStore.getState())
  mq?.addEventListener?.('change', onChange)
  return () => { unsub(); mq?.removeEventListener?.('change', onChange) }
}
```
