# Pit Wall 1.6 Plan B: Around the Race (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the "around the race" half of Pit Wall 1.6: colour-blind tyres, text size, a guided first race with persisted per-mark coaching, career stats, a "what if" replay in the debrief, a shareable result card, four new scenarios with remembered bests, and season-end team offers. Determinism, the Monte-Carlo bands and every existing save must be unaffected.

**Architecture:** Nothing in this plan changes how a race is simulated. The one engine addition, `whatIf`, is a pure function in `src/engine/debrief.ts` built from the debrief's own `replay` / `simulate` / `futureSeed` / `withPlayerPlan`, so it cannot disturb `RaceState` or the golden race. Everything else is state and UI. Settings are appended to `settingsStore` in key order. Career facts and the pending offer are optional keys, written only when present, so a 1.4 or 1.5 career serialises byte for byte as before (cloud reconcile compares the JSON). New season phases are added to `RESUME_PHASE`. Two native plugins (`@capacitor/share`, `@capacitor/filesystem`) are added for the share sheet.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess`), React 19 + framer-motion, Zustand 5, zod 4, Vitest 4 (jsdom), PixiJS 8, Capacitor 8 (Android).

**Spec:** `docs/superpowers/specs/2026-10-17-pit-wall-1.6-design.md` §5–§12 plus "Global constraints" (binding). Also read `CLAUDE.md` §3, §5 and §6.

**Runs after Plan A** (`docs/superpowers/plans/2026-10-17-pit-wall-1.6-race.md`). This plan uses only Plan A interfaces under the names the spec gives them:

## Global Constraints

Copied from the spec's "Global constraints" and applied to every task:

- The engine stays pure and deterministic: same seed + same inputs ⇒ identical race. `tests/engine/byteIdentity.test.ts` and its golden fixture pass unchanged and are **never re-captured**. New `RaceState` fields are absent (not `undefined`) on the default path. (This plan adds no `RaceState` field and no rng draw.)
- Every balance number lives in `src/data/tuning.json` with zod validation. New numbers here are `debrief.whatIfMaxShift` (10) and `career.offers.beatBy` (2) / `career.offers.stepUp` (2).
- Monte-Carlo bands: unchanged by this plan (no engine model change).
- Saves: season `SAVE_VERSION` 2, career 1, cloud 1. **No bumps.** New persisted fields are additive with zod `.optional()` / `.default()`, appended last and in the same order in schema and snapshot. The real 1.4 fixtures `tests/fixtures/season-save-1.4.json` and `tests/fixtures/career-save-1.4.json` keep loading.
- Settings keys are appended to `settingsStore` `K` and to the positional destructure in `loadSettings` **in the same order**. If Plan A appended keys, append after them.
- Race Day Bold tokens only. Volt = player / call to action. Caution = race control. Hot = urgent. Text on volt, caution or hot fills is ink. Tabular figures on live numbers. Reduced motion respected. Every new control is at least 44px and has a screen-reader label. Colour is never the only signal.
- No re-render storms: narrow Zustand subscriptions returning primitives; no per-frame allocations in Pixi.
- Never two full `vitest run`s at once. Every loop in a test is bounded.
- Scenarios depend on byte-identical engine behaviour. Author new ones with `scripts/find-scenarios.ts`: first hit meeting its brief, goal = par − 1, blurb kept true.
- `npx cap sync` runs **from the repo root at build time, never from a worktree**: a sync inside `.worktrees/` writes `../../../node_modules` into `android/capacitor.settings.gradle` and breaks the release build (`tests/data/androidManifest.test.ts` pins this). Installing dependencies happens **in the worktree**: `npm install @capacitor/share@^8.0.3 @capacitor/filesystem@^8.1.5`, the 8.x line matching the installed `@capacitor/core` 8.4.1.
- `color-mix()` is banned (`tests/ui/colorMixBan.test.ts`). Translucency is `rgba(var(--x-rgb), a)`.
- Never use `git stash`. Commit with explicit paths.

## Review Focus

The five failure modes the spec implies but does not spell out, most likely first. Each has a pinning test in the task that owns the code:

1. **A real 1.4 career, loaded and saved again by 1.6, must serialise byte for byte.** No `pendingOffer` key, and no new fact keys on old facts. Otherwise cloud reconcile sees a "different" career on every launch and may pick the wrong side. Pinned by Task 5 (`A REAL 1.4 CAREER SERIALISES BYTE FOR BYTE`) and re-run unchanged in Task 14.
2. **The app is killed while the player is picking a driver at the new team.** On resume they must land on the championship screen with the offer still pending, `seasonNumber` not advanced, and NEXT SEASON must roll the season over exactly once. Pinned by Task 14 (`APP KILLED ON THE NEW-TEAM DRIVER PICK`).
3. **A what-if result that arrives after the player has left the result screen** (NEXT RACE cancels the debrief) must be ignored and must not resurrect a panel. A what-if started after `raceStore` reset (1.5 s after the flag) must still run from the kept job. Pinned by Task 8 (`A WHAT-IF THAT LANDS AFTER THE PLAYER LEFT`).
4. **A driver radio request arriving while its own coach mark has paused the race** must not expire under the tip, and must expire normally after GOT IT. Pinned by Task 4 (`THE REQUEST DOES NOT EXPIRE UNDER ITS OWN TIP`).
5. **Career stats on a log with no Grand Prix facts, or only pre-1.6 facts** (or only sprints) must show no `NaN`, no `Infinity`, and "SINCE 1.6" where data is partial. Pinned by Task 6 (`A CAREER WITH NOTHING TO COUNT`).

Also covered beyond the five: a share card for a DNF and for a race with fewer than three classified finishers (Task 10), Large text with the compact tower at five rows (Task 2), and the colour-blind palette never touching `--hot` (Task 1).

```ts
// ── Colour-blind tyre palette (spec 1.6 §10) ──────────────────────────────
const cbStart = css.indexOf(':root[data-palette="cb"]')
const cb = cbStart < 0 ? '' : css.slice(cbStart, css.indexOf('}', cbStart))

function cbHexOf(name: string): string {
  const direct = new RegExp(`--${name}:\\s*(#[0-9A-Fa-f]{6})`).exec(cb)
  if (direct) return direct[1]!
  const rgb = new RegExp(`--${name}-rgb:\\s*(\\d+),\\s*(\\d+),\\s*(\\d+)`).exec(cb)
  if (rgb) return '#' + [rgb[1], rgb[2], rgb[3]].map(n => Number(n).toString(16).padStart(2, '0')).join('')
  throw new Error(`cb token --${name} not found`)
}
const ratioHex = (a: string, b: string) => {
  const [x, y] = [lum(a), lum(b)].sort((p, q) => q - p)
  return (x! + 0.05) / (y! + 0.05)
}
const lstar = (hex: string) => { const Y = lum(hex); return Y > 0.008856 ? 116 * Math.cbrt(Y) - 16 : 903.3 * Y }
const TYRES = ['tyre-soft', 'tyre-medium', 'tyre-hard', 'tyre-inter', 'tyre-wet']

describe('high-contrast tyre palette (spec 1.6 §10)', () => {
  it('exists', () => { expect(cbStart, 'tokens.css needs a :root[data-palette="cb"] block').toBeGreaterThan(0) })

  it.each(TYRES)('--%s is at least 3:1 on --ink', t => {
    expect(ratioHex(cbHexOf(t), hexOf('ink'))).toBeGreaterThanOrEqual(3)
  })

  it('separates soft and medium by lightness, not hue alone', () => {
    expect(Math.abs(lstar(cbHexOf('tyre-medium')) - lstar(cbHexOf('tyre-soft')))).toBeGreaterThanOrEqual(20)
  })

  it('OVERRIDES ONLY --tyre-* TOKENS, NEVER --hot', () => {
    const declared = [...cb.matchAll(/(--[\w-]+)\s*:/g)].map(m => m[1]!)
    expect(declared.length).toBeGreaterThan(0)
    expect(declared.filter(n => !n.startsWith('--tyre-')), 'only tyre tokens may change').toEqual([])
    // Soft must not simply be --hot again: the point is a different hue.
    expect(cbHexOf('tyre-soft').toLowerCase()).not.toBe(hexOf('hot').toLowerCase())
  })

  it('the standard tyre tokens are also at least 3:1 on --ink', () => {
    // --tyre-soft aliases --hot, which hexOf cannot read through var(); check --hot itself.
    for (const t of ['hot', 'tyre-medium', 'tyre-hard', 'tyre-inter', 'tyre-wet']) {
      expect(ratioHex(hexOf(t), hexOf('ink')), t).toBeGreaterThanOrEqual(3)
    }
  })

  it('--lilac-rgb matches --lilac', () => {
    const rgb = /--lilac-rgb:\s*(\d+),\s*(\d+),\s*(\d+)/.exec(root)
    expect(rgb, '--lilac-rgb must exist for translucent lilac').not.toBeNull()
    const hex = '#' + [rgb![1], rgb![2], rgb![3]].map(n => Number(n).toString(16).padStart(2, '0')).join('')
    expect(hex.toUpperCase()).toBe(/--lilac:\s*(#[0-9A-Fa-f]{6})/.exec(root)![1]!.toUpperCase())
  })
})
```

```ts
import { useSettingsStore, type SettingsState } from './settingsStore'

/**
 * Display preferences live on the ROOT element as data attributes, so CSS
 * (tokens.css) does the work and no component re-renders when they change.
 * Spec 1.6 §10 (tyre palette); §11 (text size) adds to this in Task 2.
 */
export function applyDisplaySettings(root: HTMLElement, s: Pick<SettingsState, 'tyrePalette'>): void {
  if (s.tyrePalette === 'cb') root.setAttribute('data-palette', 'cb')
  else root.removeAttribute('data-palette')
}

/** Applies now, then follows the store. Returns an unsubscribe. */
export function startDisplaySettingsSync(root: HTMLElement = document.documentElement): () => void {
  applyDisplaySettings(root, useSettingsStore.getState())
  return useSettingsStore.subscribe(s => applyDisplaySettings(root, s))
}
```

```ts
 * Career statistics (spec 1.6 §7). PURE: no store, no React -- the same
 * discipline as badges.ts, so every number on the STATS screen is a fold over

/**
 * The longest run of completed laps on one set of tyres. `changeLaps` are the
 * completed-lap counts at each tyre change; `lapsRun` is the car's completed
 * laps at the flag (or at retirement).
 */
export function longestStint(changeLaps: readonly number[], lapsRun: number): number {
  const marks = [0, ...changeLaps, lapsRun]
  let best = 0
  for (let i = 1; i < marks.length; i++) best = Math.max(best, marks[i]! - marks[i - 1]!)
  return Math.max(0, best)
```

```ts
import type { RaceFact } from './badges'
import type { Compound } from '@engine/types'

export interface RecordLine { races: number; wins: number; podiums: number; best: number | null }
export interface CareerStatsView {
  gpRaces: number
  bestByCircuit: { circuitId: string; best: number | null; races: number }[]
  circuitPartial: boolean
  byStartCompound: { compound: Compound; races: number; winRate: number; podiumRate: number }[]
  compoundPartial: boolean
  longestStint: number | null
  stintPartial: boolean
  biggestComeback: { gained: number; season: number; round: number } | null
  wet: RecordLine
  sprint: RecordLine
  dnfRate: number | null
  averageBySeason: { season: number; races: number; average: number | null }[]
}

const COMPOUND_ORDER: Compound[] = ['S', 'M', 'H', 'I', 'W']
const classified = (f: RaceFact) => !f.retired
const won = (f: RaceFact) => classified(f) && f.finish === 1
const podium = (f: RaceFact) => classified(f) && f.finish <= 3

function recordOf(facts: readonly RaceFact[]): RecordLine {
  const fin = facts.filter(classified).map(f => f.finish)
  return {
    races: facts.length, wins: facts.filter(won).length, podiums: facts.filter(podium).length,
    best: fin.length ? Math.min(...fin) : null,
  }
}

/** Every number on the STATS screen. Grand Prix facts only, except `sprint` and `longestStint` (plan Task 6 ruling). */
export function careerStats(log: readonly RaceFact[], circuitOrder: readonly string[]): CareerStatsView {
  const gp = log.filter(f => f.kind !== 'sprint')
  const sprints = log.filter(f => f.kind === 'sprint')

  const bestByCircuit = circuitOrder.map(circuitId => {
    const here = gp.filter(f => f.circuitId === circuitId)
    const fin = here.filter(classified).map(f => f.finish)
    return { circuitId, best: fin.length ? Math.min(...fin) : null, races: here.length }
  })

  const byStartCompound = COMPOUND_ORDER.flatMap(compound => {
    const on = gp.filter(f => f.startCompound === compound)
    return on.length === 0 ? [] : [{
      compound, races: on.length,
      winRate: on.filter(won).length / on.length,
      podiumRate: on.filter(podium).length / on.length,
    }]
  })

  const stints = log.map(f => f.longestStint).filter((n): n is number => n !== undefined)

  let biggestComeback: CareerStatsView['biggestComeback'] = null
  for (const f of gp) {
    const gained = f.grid - f.finish
    if (classified(f) && gained > 0 && (!biggestComeback || gained > biggestComeback.gained)) {
      biggestComeback = { gained, season: f.season, round: f.round }
    }
  }

  const seasons = [...new Set(gp.map(f => f.season))].sort((a, b) => a - b)
  const averageBySeason = seasons.map(season => {
    const inSeason = gp.filter(f => f.season === season)
    const fin = inSeason.filter(classified).map(f => f.finish)
    return { season, races: inSeason.length, average: fin.length ? fin.reduce((a, b) => a + b, 0) / fin.length : null }
  })

  return {
    gpRaces: gp.length,
    bestByCircuit,
    circuitPartial: gp.some(f => f.circuitId === undefined),
    byStartCompound,
    compoundPartial: gp.some(f => f.startCompound === undefined),
    longestStint: stints.length ? Math.max(...stints) : null,
    stintPartial: log.some(f => f.longestStint === undefined),
    biggestComeback,
    wet: recordOf(gp.filter(f => f.wet)),
    sprint: recordOf(sprints),
    dnfRate: gp.length ? gp.filter(f => f.retired).length / gp.length : null,
    averageBySeason,
  }
}
```

The method is the spec's (§5) and the judge's. Replay the real race up to **two laps before the earliest change**: `branchStep = max(0, min(oldStep, newStep) − 6)`. Then run `debrief.futures` continuations with `futureSeed(seed, branchStep, k)` for the real plan (`mine`) and for the edited plan (`theirs`) from the same shared past. That is common random numbers: future *k* draws the same randomness in both. A plan-stop edit rewrites `playerStrategyOverride` and patches the car via `withPlayerPlan`. A pit-call edit moves the call by `3 × Δlap` steps and swaps its compound. "Add a stop" adds a pit call at step `3 × (lap − 1)`, so the stop happens at the start of display lap `lap`.

**Ruling recorded for Veet:** the lap range for an existing stop is `[max(1, lap − 10, previous stop + 1), min(totalLaps − 1, lap + 10, next stop − 1)]`, so an edit can never reorder the stops. "Add a stop" ranges over `[2, totalLaps − 1]`. The ±10 is `tuning.debrief.whatIfMaxShift`. Laps outside the range are clamped, never rejected. An `add` on a race that has stops, or a stop index that does not exist, throws `RangeError`, because the UI never builds one.

```ts
// ---- "What if" (spec 1.6 §5) -------------------------------------------------

export interface PlayerStop {
  lap: number
  compound: Compound
  source: { kind: 'plan'; index: number } | { kind: 'call'; index: number }
  step: number
}
export type WhatIfEdit =
  | { kind: 'stop'; stop: number; lap: number; compound: Compound }
  | { kind: 'add'; lap: number; compound: Compound }
export interface WhatIfResult { mine: number[]; theirs: number[] }

/**
 * The player's stops as the race ran them, in order. Same walk as judgeCalls:
 * calls apply before the step at their step; any pitsDone increase across a
 * step is the plan's (plannedStops is indexed by pitsDone).
 */
export function playerStops(config: RaceConfig, seed: number, calls: readonly PlayerCall[]): PlayerStop[] {
  const rng = createRng(seed)
  let state = initRace(config)
  let step = 0
  const sorted = calls.map((c, index) => ({ c, index })).sort((a, b) => a.c.step - b.c.step)
  const me = (s: RaceState) => s.cars.find(c => c.isPlayer)!
  const stops: PlayerStop[] = []
  let i = 0
  for (;;) {
    while (i < sorted.length && sorted[i]!.c.step === step) {
      const { c, index } = sorted[i]!
      const before = me(state).pitsDone
      const lapNow = state.lap
      state = applyCall(config, state, c, rng)
      if (c.kind === 'pit' && me(state).pitsDone > before) {
        stops.push({ lap: lapNow + 1, compound: me(state).compound, source: { kind: 'call', index }, step })
      }
      i++
    }
    const pitsBefore = me(state).pitsDone
    if (isFinished(state)) break
    state = stepSector(config, state, rng)
    step++
    if (me(state).pitsDone > pitsBefore) {
      const planned = config.playerStrategyOverride?.plannedStops[pitsBefore]
      if (planned) stops.push({ lap: planned.lap, compound: me(state).compound, source: { kind: 'plan', index: pitsBefore }, step })
    }
  }
  return stops
}

/** Where stop `index` may move: ±maxShift, inside the race, never past a neighbouring stop. */
export function whatIfLapRange(stops: readonly PlayerStop[], index: number, totalLaps: number, maxShift: number): [number, number] {
  const s = stops[index]
  if (!s) throw new RangeError(`whatIfLapRange: no stop ${index}`)
  const prev = stops[index - 1]?.lap ?? 0
  const next = stops[index + 1]?.lap ?? totalLaps
  return [Math.max(1, s.lap - maxShift, prev + 1), Math.min(totalLaps - 1, s.lap + maxShift, next - 1)]
}

/** "Add a stop on lap N" when the player made none: lap 2 to the last lap but one. */
export function addStopLapRange(totalLaps: number): [number, number] {
  return [2, totalLaps - 1]
}

const clampTo = (v: number, [lo, hi]: [number, number]) => Math.min(hi, Math.max(lo, v))

/**
 * The real plan against one edited stop, over debrief.futures continuations
 * branched two laps before the earliest change, with common random numbers.
 * Finishes per future (a DNF is cars + 1). Never one "exact" result: the
 * caller shows a typical finish and a range.
 */
export function whatIf(config: RaceConfig, seed: number, calls: readonly PlayerCall[], edit: WhatIfEdit): WhatIfResult {
  const { futures, whatIfMaxShift } = config.tuning.debrief
  const totalLaps = initRace(config).totalLaps
  const stops = playerStops(config, seed, calls)

  let edConfig = config
  let edCalls: readonly PlayerCall[] = calls
  let changeStep: number
  if (edit.kind === 'add') {
    if (stops.length > 0) throw new RangeError('whatIf: "add" is only for a race without a stop')
    const lap = clampTo(edit.lap, addStopLapRange(totalLaps))
    const newStep = 3 * (lap - 1)
    edCalls = [...calls, { step: newStep, kind: 'pit', compound: edit.compound }]
    changeStep = newStep
  } else {
    const s = stops[edit.stop]
    if (!s) throw new RangeError(`whatIf: no stop ${edit.stop}`)
    const lap = clampTo(edit.lap, whatIfLapRange(stops, edit.stop, totalLaps, whatIfMaxShift))
    if (s.source.kind === 'plan') {
      const idx = s.source.index
      edConfig = withPlan(config, p => ({
        ...p, plannedStops: p.plannedStops.map((x, j) => (j === idx ? { lap, compound: edit.compound } : x)),
      }))
      changeStep = Math.min(s.step, 3 * lap)
    } else {
      const idx = s.source.index
      const call = calls[idx]
      if (!call || call.kind !== 'pit') throw new RangeError(`whatIf: call ${idx} is not a pit call`)
      const moved: PlayerCall = { step: call.step + 3 * (lap - s.lap), kind: 'pit', compound: edit.compound }
      edCalls = calls.map((c, j) => (j === idx ? moved : c))
      changeStep = Math.min(call.step, moved.step)
    }
  }

  const branchStep = Math.max(0, changeStep - 6)
  const shared = replay(config, seed, calls, branchStep)
  const run = (cfg: RaceConfig, cl: readonly PlayerCall[]) => {
    const out: number[] = []
    for (let k = 0; k < futures; k++) {
      const end = simulate(cfg, { state: withPlayerPlan(shared.state, cfg), step: shared.step },
        createRng(futureSeed(seed, branchStep, k)), cl)
      out.push(finishPosition(end.state))
    }
    return out
  }
  return { mine: run(config, calls), theirs: run(edConfig, edCalls) }
}
```

```ts
import { loadGameData } from '@data/validators'

/** The share PNG (spec 1.6 §6): 1080 x 1350, a 4:5 portrait that every share target accepts. */
export const SHARE_W = 1080
export const SHARE_H = 1350

/**
 * Canvas cannot read CSS custom properties, so the card's colours are the
 * Race Day Bold tokens MIRRORED here and pinned to tokens.css by
 * tests/ui/shareCard.test.ts. Always the standard palette: the card is for
 * other people, not a per-player accessibility view.
 */
export const SHARE_COLORS = { ink: '#120E2B', grape: '#2A2160', volt: '#FFD60A', white: '#FFFFFF', lilacDim: '#A99FDB' } as const

const DISPLAY = '"Big Shoulders Display"'
const BODY = 'Barlow'
const PAD = 120
const MAX = SHARE_W - PAD   // every fillText gets a maxWidth: a long name shrinks, never runs off

export interface ShareCardData {
  kind: 'gp' | 'sprint' | 'season'
  /** null = DNF. */
  position: number | null
  label: string
  points: number
  /** Driver codes, P1 first; up to three. */
  podium: string[]
  teamColor: string
}

export type ShareCtx = Pick<CanvasRenderingContext2D,
  'fillStyle' | 'font' | 'textAlign' | 'textBaseline' | 'fillRect' | 'fillText' | 'beginPath' | 'moveTo' | 'lineTo' | 'closePath' | 'fill'>

export function buildShareData(i: {
  kind: ShareCardData['kind']; finish: number | null; circuitName?: string; round?: number; season: number
  points: number; podiumIds: readonly string[]; playerDriverId: string | null
}): ShareCardData {
  const data = loadGameData()
  const code = (id: string) => data.drivers.drivers.find(d => d.id === id)?.code ?? id.replace('d_', '').slice(0, 3).toUpperCase()
  const teamId = data.drivers.drivers.find(d => d.id === i.playerDriverId)?.teamId
  const teamColor = data.cars.teams.find(t => t.id === teamId)?.colorPrimary ?? SHARE_COLORS.grape
  const label = i.kind === 'season'
    ? `SEASON ${i.season} · ${i.finish === 1 ? 'CHAMPION' : 'FINAL STANDINGS'}`
    : i.kind === 'sprint'
      ? `${i.circuitName ?? ''} · ROUND ${i.round ?? 0} · SPRINT`
      : `${i.circuitName ?? ''} · ROUND ${i.round ?? 0} · SEASON ${i.season}`
  return { kind: i.kind, position: i.finish, label, points: i.points, podium: i.podiumIds.slice(0, 3).map(code), teamColor }
}

function poly(ctx: ShareCtx, pts: readonly [number, number][]) {
  ctx.beginPath()
  pts.forEach(([x, y], k) => (k === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y)))
  ctx.closePath()
  ctx.fill()
}

export function drawShareCard(ctx: ShareCtx, d: ShareCardData): void {
  const dnf = d.position === null
  ctx.textAlign = 'left'
  ctx.textBaseline = 'alphabetic'

  ctx.fillStyle = SHARE_COLORS.ink
  ctx.fillRect(0, 0, SHARE_W, SHARE_H)
  // Team colour slash down the left edge (the one forward slant).
  ctx.fillStyle = d.teamColor
  poly(ctx, [[0, 0], [84, 0], [36, SHARE_H], [0, SHARE_H]])
  // Hero band: volt, or grape on a DNF (a retirement is not a celebration).
  ctx.fillStyle = dnf ? SHARE_COLORS.grape : SHARE_COLORS.volt
  poly(ctx, [[0, 150], [SHARE_W, 90], [SHARE_W, 770], [0, 830]])

  const onBand = dnf ? SHARE_COLORS.white : SHARE_COLORS.ink
  ctx.fillStyle = onBand
  ctx.font = `800 40px ${BODY}`
  ctx.fillText(d.label, PAD, 270, MAX - PAD)
  ctx.font = `italic 900 440px ${DISPLAY}`
  ctx.fillText(dnf ? 'DNF' : `P${d.position}`, PAD - 10, 660, MAX - PAD)
  ctx.font = `italic 900 100px ${DISPLAY}`
  ctx.fillText(d.kind === 'season' ? `${d.points} PTS` : d.points > 0 ? `+${d.points} PTS` : 'NO POINTS', PAD, 750, MAX - PAD)

  if (d.podium.length > 0) {
    ctx.fillStyle = SHARE_COLORS.lilacDim
    ctx.font = `800 34px ${BODY}`
    ctx.fillText(d.kind === 'season' ? 'TOP THREE' : 'PODIUM', PAD, 930, MAX - PAD)
    ctx.fillStyle = SHARE_COLORS.white
    ctx.font = `italic 900 84px ${DISPLAY}`
    d.podium.forEach((c, k) => ctx.fillText(`${k + 1} ${c}`, PAD + k * 300, 1020, 280))
  }

  ctx.fillStyle = SHARE_COLORS.volt
  ctx.font = `italic 900 96px ${DISPLAY}`
  ctx.fillText('PIT WALL', PAD, 1250, MAX - PAD)
}

/** The self-hosted faces must be loaded before drawing, or the canvas silently falls back to sans. */
export async function loadShareFonts(): Promise<void> {
  if (typeof document === 'undefined' || !('fonts' in document)) return
  await Promise.all([
    document.fonts.load(`italic 900 100px ${DISPLAY}`),
    document.fonts.load(`800 40px ${BODY}`),
  ])
}

export async function renderShareCard(d: ShareCardData): Promise<Blob> {
  await loadShareFonts()
  const canvas = document.createElement('canvas')
  canvas.width = SHARE_W
  canvas.height = SHARE_H
  const ctx = canvas.getContext('2d')
  if (!ctx) throw new Error('share card: no 2d context')
  drawShareCard(ctx, d)
  return new Promise((res, rej) => canvas.toBlob(b => (b ? res(b) : rej(new Error('share card: toBlob failed'))), 'image/png'))
}
```

```ts
import { Capacitor } from '@capacitor/core'
import { Filesystem, Directory } from '@capacitor/filesystem'
import { Share } from '@capacitor/share'

export type ShareOutcome = 'shared' | 'cancelled' | 'downloaded' | 'failed'

function base64Of(blob: Blob): Promise<string> {
  return new Promise((res, rej) => {
    const r = new FileReader()
    r.onload = () => res(String(r.result).replace(/^data:[^,]*,/, ''))
    r.onerror = () => rej(r.error)
    r.readAsDataURL(blob)
  })
}

/**
 * Android: write to the app cache (served by the manifest's FileProvider
 * cache-path) and open the system share sheet. Web: download the PNG.
 * Nothing leaves the device except what the player chooses to share.
 * Never throws: every failure is an outcome.
 */
export async function sharePng(blob: Blob, fileName: string, title: string): Promise<ShareOutcome> {
  try {
    if (Capacitor.isNativePlatform()) {
      const { uri } = await Filesystem.writeFile({ path: fileName, data: await base64Of(blob), directory: Directory.Cache })
      try {
        await Share.share({ title, files: [uri], dialogTitle: title })
        return 'shared'
      } catch (e) {
        return /cancel/i.test(String(e)) ? 'cancelled' : 'failed'
      }
    }
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = fileName
    document.body.appendChild(a)
    a.click()
    a.remove()
    setTimeout(() => URL.revokeObjectURL(url), 0)
    return 'downloaded'
  } catch {
    return 'failed'
  }
}
```

```ts
import { create } from 'zustand'
import { z } from 'zod'
import { Preferences } from '@capacitor/preferences'
import type { ScenarioSpecData } from '@data/validators'

export interface ScenarioOutcome { met: boolean; position: number; retired: boolean }
/** position null = DNF. */
export interface ScenarioBest { position: number | null; met: boolean }
export const SCENARIO_BEST_KEY = 'scenarios.best'

const BestSchema = z.record(z.string(), z.object({ position: z.number().nullable(), met: z.boolean() }))

/** Met beats unmet; then the better finish; a DNF ranks below any finish (spec 1.6 §8). */
export function betterBest(a: ScenarioBest | undefined, b: ScenarioBest): ScenarioBest {
  if (!a) return b
  if (a.met !== b.met) return a.met ? a : b
  if (a.position === null) return b
  if (b.position === null) return a
  return b.position < a.position ? b : a
}

async function readBest(): Promise<Record<string, ScenarioBest>> {
  try {
    const { value } = await Preferences.get({ key: SCENARIO_BEST_KEY })
    const parsed = BestSchema.safeParse(value ? JSON.parse(value) : {})
    return parsed.success ? parsed.data : {}
  } catch { return {} }
}

interface ScenarioStore {
  active: ScenarioSpecData | null
  outcome: ScenarioOutcome | null
  best: Record<string, ScenarioBest>
  select: (spec: ScenarioSpecData) => void
  recordOutcome: (outcome: ScenarioOutcome) => void
  loadBest: () => Promise<void>
  exit: () => void
}

/**
 * Scenario mode's own state, deliberately NOT part of seasonStore -- a
 * scenario can never write into a saved championship. Its one persisted thing
 * is the per-scenario best (spec 1.6 §8), under its own Preferences key.
 */
export const useScenarioStore = create<ScenarioStore>((set, get) => ({
  active: null,
  outcome: null,
  best: {},
  select: (spec) => set({ active: spec, outcome: null }),
  recordOutcome: (outcome) => {
    const id = get().active?.id
    if (!id) { set({ outcome }); return }
    const entry: ScenarioBest = { position: outcome.retired ? null : outcome.position, met: outcome.met }
    set(s => ({ outcome, best: { ...s.best, [id]: betterBest(s.best[id], entry) } }))
    // Read-merge-write: a result recorded before loadBest resolved must not wipe older bests.
    void (async () => {
      const stored = await readBest()
      const merged = { ...stored, [id]: betterBest(stored[id], entry) }
      await Preferences.set({ key: SCENARIO_BEST_KEY, value: JSON.stringify(merged) })
      set(s => ({ best: { ...merged, ...Object.fromEntries(Object.entries(s.best).map(([k, v]) => [k, betterBest(merged[k], v)])) } }))
    })()
  },
  loadBest: async () => {
    const stored = await readBest()
    set(s => ({ best: { ...stored, ...Object.fromEntries(Object.entries(s.best).map(([k, v]) => [k, betterBest(stored[k], v)])) } }))
  },
  exit: () => set({ active: null, outcome: null }),
}))
```

Rules (spec §12, all deterministic, no rng):
- **Board target** = the team's **deserved constructors' rank** from `deservedOrder`, over the cars as they stand: `effectiveTeams(playerDriverId, overlay)`, the same overlay `settleSeason` judges. There is no penalty for missing it.
- **Offer** at season end, after the ladder settles, only on the banked path: if `deserved − finished ≥ career.offers.beatBy` (2), or the player won the drivers' title, then the team `career.offers.stepUp` (2) places higher in `offerOrder(settledTiers)` makes an offer, clamped to the top team. There is none if the player's team is already top. At most one, because there is one call per banked season.
- **Accept:** NEXT SEASON with ACCEPT goes to `new_team_driver`, where the player picks one of the new team's two drivers. Confirming rolls the season over **for the old seat first**: the title bonus winter and the history entry belong to the season just raced. It then sets `playerDriverId` and `selectedTeamId` together, resets `purchasedTiers` to `{}` (team tiers stay with the old team; driver pace is a new driver), and clears the offer. `devPoints` and `wingByCircuit` carry over, and `teamTiers` (the ladder) are untouched.
- **Decline / ignore:** NEXT SEASON with STAY clears the offer. An offer never outlives its season-end screen.

**Ruling recorded for Veet:** "places higher by effective rating (ladder offsets included)" is read as the ratings the next season starts from: authored facets plus the **settled** ladder offsets, with no player purchases and no rival development. Those two are season-scoped and are erased or reset by the winter. The offer card's "its car rating vs yours" uses the same basis, rounded to whole numbers, so the two cars are compared like for like. The offered team's board target is its rank in that order. `reason` is `'title'` whenever the player won the drivers' title, otherwise `'constructors'`. The app killed during the new-team pick resumes on the championship screen with the offer still pending (`RESUME_PHASE.new_team_driver = 'championship'`). Nothing has been rolled over at that point, so NEXT SEASON rolls exactly once.

```ts
import { loadGameData } from '@data/validators'
import { effectiveTeams } from './buildRaceConfig'
import { deservedOrder, meanFacet } from './teamLadder'
import type { UpgradeOverlayInput } from './upgradeOverlay'
import type { PendingOffer } from './careerStore'

/**
 * Team offers (spec 1.6 §12). Pure and rng-free. Imports careerStore for a
 * TYPE only, so seasonStore can call it without an ESM cycle.
 */

/** Every team, best first, on authored facets + ladder offsets only -- what next season starts from. */
export function offerOrder(tiers: Readonly<Record<string, number>>): { order: string[]; ratings: Record<string, number> } {
  const data = loadGameData()
  // '__none__' matches no driver: no player purchases, no rival development, offsets still applied.
  const teams = effectiveTeams('__none__', { purchasedTiers: {}, rivalDevelopment: {}, teamTiers: { ...tiers } })
  const ratings = Object.fromEntries(teams.map(t => [t.id, meanFacet(t.facets)]))
  const base = Object.fromEntries(data.cars.teams.map(t => [t.id, meanFacet(t.facets)]))
  return { order: deservedOrder(ratings, base), ratings }
}

/** The board's yardstick: where the player's car, as it stands, deserves to finish in the constructors'. */
export function boardTarget(playerDriverId: string, overlay: UpgradeOverlayInput): number | null {
  const data = loadGameData()
  const team = data.drivers.drivers.find(d => d.id === playerDriverId)?.teamId
  if (!team) return null
  const teams = effectiveTeams(playerDriverId, overlay)
  const ratings = Object.fromEntries(teams.map(t => [t.id, meanFacet(t.facets)]))
  const base = Object.fromEntries(data.cars.teams.map(t => [t.id, meanFacet(t.facets)]))
  const i = deservedOrder(ratings, base).indexOf(team)
  return i < 0 ? null : i + 1
}

export function seasonOffer(a: {
  season: number; teamId: string; deserved: number; finished: number; wonTitle: boolean
  tiers: Readonly<Record<string, number>>; beatBy: number; stepUp: number
}): PendingOffer | null {
  if (!(a.deserved - a.finished >= a.beatBy || a.wonTitle)) return null
  const { order, ratings } = offerOrder(a.tiers)
  const i = order.indexOf(a.teamId)
  if (i <= 0) return null
  const j = Math.max(0, i - a.stepUp)
  const teamId = order[j]!
  return {
    season: a.season, teamId, reason: a.wonTitle ? 'title' : 'constructors',
    boardTarget: j + 1, rating: Math.round(ratings[teamId] ?? 0), currentRating: Math.round(ratings[a.teamId] ?? 0),
  }
}
```
