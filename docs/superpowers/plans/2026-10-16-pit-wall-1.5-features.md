# Pit Wall 1.5 Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Pit Wall 1.5: a virtual safety car (with AI teams reacting to every neutralisation), a lap chart in the debrief, tap-for-rival-intel on the timing tower, and three sprint weekends, without breaking determinism, the Monte-Carlo bands or anyone's save.

**Architecture:** Every mechanic lands in the pure engine first (`src/engine/`, stepable, seeded, all numbers in `tuning.json`), behind rolls that short-circuit with no rng draw at a zero rate, so the byte-identity golden race still reproduces with the new chances zeroed. Derived views (lap history, rival intel) are pure engine functions over the existing replay/state, so the UI only reads. Sprint weekends are a state-layer flow (new season phases, own seed salt, own attempt counter, pending/keep banking) over the same engine with a laps override and the two-compound rule off.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess`), React 19 + framer-motion, Zustand 5, zod 4, Vitest 4 (jsdom), PixiJS 8 (track canvas), Capacitor 8 (Android).

**Spec:** `docs/superpowers/specs/2026-10-16-pit-wall-1.5-features-design.md` (approved; binding). Also read `CLAUDE.md` and `MODEL_SPEC.md` §3, §10, §12.

## Global Constraints

- Same seed + same inputs ⇒ identical race. New rng draws only on paths that are off when their tuning rate is 0, and short-circuit with no draw at 0 (`MODEL_SPEC.md` invariants).
- The byte-identity golden fixture must still pass unchanged with the new features' chances zeroed in the fixture tuning (`tests/fixtures/tuning.ts` `makeDeterministicTuning`). Never re-capture it.
- Existing saves (season `SAVE_VERSION 2`, career `1`, cloud `1`) load without loss. New persisted fields are additive with zod `.default()`; no version bump.
- Race Day Bold tokens only; volt = the player / call to action; caution = race control (SC and VSC); text on volt/caution is ink.
- Tabular figures on all live numbers. Reduced motion respected.
- Every new control has a screen-reader label and is at least 44px.
- Monte-Carlo regression bands: all existing bands still hold; new bands `vscPerRace` and `aiNeutralisationStopsPerRace` are measured and written into `tuning.json._regressionBands` and `MODEL_SPEC.md`.
- Every balance number lives in `src/data/tuning.json`. The engine imports nothing from `state/`, `ui/` or `canvas/`.
- Start values (all tunable, all flagged for Veet): VSC chances crash 0.25 / mechanical 0.40, VSC pace 1.30, VSC lane factor 0.60, VSC duration 1–3 laps, VSC max 2 per race, AI window 6 laps / cliff 0.55, intel half-widths naive 2 / smart 3 / optimal 5, sprint fraction 0.33, sprint rounds 4/8/12, sprint points 8-7-6-5-4-3-2-1.
- Ships as 1.5, versionCode 6.

```ts
import { describe, it, expect } from 'vitest'
import { initRace, stepSector, computeSectorTime } from '@engine/index'
import { createRng } from '@engine/rng'
import {
  neutralisationKind, rollVscDeployment, rollVscDuration,
  neutralisationPaceMultiplier, effectivePitLaneLoss,
} from '@engine/incidents'
import { loadGameData } from '@data/validators'
import { makeTuning } from '../fixtures/tuning'
import type { RaceConfig, RaceState, SafetyCarState, IncidentEvent } from '@engine/types'

const DATA = loadGameData()
type TuningOverrides = Parameters<typeof makeTuning>[0]

// The spec's start values with the chances switched on. tuning.json ships the
// chances at 0 until Task 2, so every test states the VSC it wants.
const VSC_ON = {
  crashDeployChance: 0.25, mechanicalDeployChance: 0.40, paceMultiplier: 1.30,
  laneLossFactor: 0.60, durationLapsMin: 1, durationLapsMax: 3, maxPerRace: 2,
}

// Every retirement is a crash, the SC never comes out, a crash always brings the VSC.
const VSC_CERTAIN = {
  incidents: {
    driverErrorPerLap: 0.05, terminalFraction: 1,
    safetyCar: { crashDeployChance: 0, mechanicalDeployChance: 0 },
    vsc: { ...VSC_ON, crashDeployChance: 1, mechanicalDeployChance: 0 },
  },
  mechanicalFailure: { baseChancePerLap: 0 },
  tyreFailure: { chancePerLapOverThreshold: 0, maxChancePerLap: 0 },
}

function makeConfig(overrides: TuningOverrides, seed: number, circuitId = 'bengaluru'): RaceConfig {
  return {
    circuit: DATA.circuits[circuitId]!,
    tuning: makeTuning(overrides),
    compounds: DATA.compounds,
    drivers: DATA.drivers.drivers,
    teams: DATA.cars.teams,
    strategies: DATA.strategies.defaults,
    playerDriverId: '__none__',
    seed,
  }
}

function runRace(config: RaceConfig, seed: number, onTick?: (prev: RaceState, next: RaceState) => void): RaceState {
  let state = initRace(config)
  const rng = createRng(seed)
  for (let i = 0; i < config.circuit.laps * 3; i++) {
    const next = stepSector(config, state, rng)
    onTick?.(state, next)
    state = next
  }
  return state
}

const NEUTRALISATION_KINDS = ['safety_car_deployed', 'safety_car_ended', 'vsc_deployed', 'vsc_ended']
const neutralisationEvents = (incidents: IncidentEvent[]) => incidents.filter(i => NEUTRALISATION_KINDS.includes(i.kind))

describe('VSC rolls', () => {
  it('DRAWS NOTHING when both VSC chances are zero', () => {
    const zeroed = makeTuning({ incidents: { vsc: { crashDeployChance: 0, mechanicalDeployChance: 0 } } })
    let draws = 0
    const counting = () => { draws++; return 0.5 }
    for (const cause of ['crash', 'mechanical'] as const) {
      for (let i = 0; i < 100; i++) expect(rollVscDeployment(cause, zeroed, counting)).toBe(false)
    }
    expect(draws, 'rng() must not be called at a zero VSC chance').toBe(0)
  })

  it('converges on the configured chance for each cause', () => {
    const T = makeTuning({ incidents: { vsc: VSC_ON } })
    const N = 20_000
    for (const [cause, p] of [['crash', 0.25], ['mechanical', 0.40]] as const) {
      const rng = createRng(cause === 'crash' ? 31 : 37)
      let hits = 0
      for (let i = 0; i < N; i++) if (rollVscDeployment(cause, T, rng)) hits++
      const se = Math.sqrt(p * (1 - p) / N)
      expect(Math.abs(hits / N - p), `${cause} VSC rate`).toBeLessThan(4 * se)
    }
  })

  it('duration stays within the inclusive bounds and covers them', () => {
    const T = makeTuning({ incidents: { vsc: VSC_ON } })
    const rng = createRng(19)
    const seen = new Set<number>()
    for (let i = 0; i < 5_000; i++) {
      const d = rollVscDuration(T, rng)
      expect(d).toBeGreaterThanOrEqual(1)
      expect(d).toBeLessThanOrEqual(3)
      seen.add(d)
    }
    expect([...seen].sort()).toEqual([1, 2, 3])
  })
})

describe('neutralisation kind, pace and pit loss', () => {
  const T = makeTuning({ incidents: { vsc: VSC_ON } })
  const legacy: SafetyCarState = { deployedLap: 4, lapsRemaining: 2, cause: 'crash' }
  const vsc: SafetyCarState = { ...legacy, kind: 'vsc' }
  const sc: SafetyCarState = { ...legacy, kind: 'sc' }

  it('reads a missing kind as the safety car, so older states keep their meaning', () => {
    expect(neutralisationKind(null)).toBeNull()
    expect(neutralisationKind(legacy)).toBe('sc')
    expect(neutralisationKind(sc)).toBe('sc')
    expect(neutralisationKind(vsc)).toBe('vsc')
  })

  it('scales pace by the kind in force', () => {
    expect(neutralisationPaceMultiplier(null, T)).toBe(1)
    expect(neutralisationPaceMultiplier(sc, T)).toBe(T.incidents.safetyCar.paceMultiplier)
    expect(neutralisationPaceMultiplier(legacy, T)).toBe(T.incidents.safetyCar.paceMultiplier)
    expect(neutralisationPaceMultiplier(vsc, T)).toBe(1.30)
  })

  it('prices a VSC stop at the circuit loss times laneLossFactor, an SC stop at laneTimeLossUnderSc', () => {
    const circuit = DATA.circuits['bengaluru']!   // pitLaneTimeLoss 20
    expect(effectivePitLaneLoss(circuit, null, T)).toBe(20)
    expect(effectivePitLaneLoss(circuit, vsc, T)).toBeCloseTo(12, 9)
    expect(effectivePitLaneLoss(circuit, sc, T)).toBe(T.incidents.safetyCar.laneTimeLossUnderSc)
    expect(effectivePitLaneLoss(circuit, legacy, T)).toBe(T.incidents.safetyCar.laneTimeLossUnderSc)

  it('a crash deploys the VSC when the SC does not come out', () => {
    const config = makeConfig(VSC_CERTAIN as TuningOverrides, 5)

describe('supersession', () => {
  // One car (index 5) errs on every sector and every error is terminal; the
  // other nineteen have consistency 100, which with consistencyReliefMax 1 makes
  // their error chance exactly 0, so the roll short-circuits for them.
  const ONE_CRASH = {
    incidents: {
      driverErrorPerLap: 3, consistencyReliefMax: 1, terminalFraction: 1,
      safetyCar: { crashDeployChance: 1, mechanicalDeployChance: 0 },
      vsc: { ...VSC_ON, crashDeployChance: 1, mechanicalDeployChance: 1 },
    },
    mechanicalFailure: { baseChancePerLap: 0 },
    tyreFailure: { chancePerLapOverThreshold: 0, maxChancePerLap: 0 },
  }
  function crashConfig(gapCompression: number): RaceConfig {
    const base = makeConfig({ ...ONE_CRASH, incidents: { ...ONE_CRASH.incidents, safetyCar: { ...ONE_CRASH.incidents.safetyCar, gapCompression } } } as TuningOverrides, 9)
    return {
      ...base,
      drivers: base.drivers.map((d, i) => ({ ...d, facets: { ...d.facets, consistency: i === 5 ? 0 : 100 } })),
    }
  }
  function midRace(config: RaceConfig): RaceState {
    const calm: RaceConfig = { ...config, tuning: { ...config.tuning, incidents: { ...config.tuning.incidents, driverErrorPerLap: 0 } } }
    let s = initRace(calm)
    const rng = createRng(9)
    for (let i = 0; i < 30; i++) s = stepSector(calm, s, rng)
    return s
  }
  const spread = (s: RaceState) => {
    const active = s.cars.filter(c => !c.retired)
    const lead = Math.min(...active.map(c => c.raceTime))
    return Math.max(...active.map(c => c.raceTime - lead))
  }

  it('an SC SUPERSEDES a running VSC: vsc_ended then safety_car_deployed on the same tick, and the field is compressed', () => {
    const run = (gapCompression: number) => {
      const config = crashConfig(gapCompression)
      const mid = midRace(config)
      const withVsc: RaceState = {
        ...mid,
        safetyCar: { deployedLap: mid.lap, lapsRemaining: 3, cause: 'mechanical', kind: 'vsc' },
        incidents: [...mid.incidents, { lap: mid.lap, sector: 0, kind: 'vsc_deployed', driverId: null, timeLoss: null }],
      }
      return { before: withVsc, after: stepSector(config, withVsc, createRng(4)) }
    }
    const { before, after } = run(0.35)
    expect(after.safetyCar?.kind).toBe('sc')
    const fresh = neutralisationEvents(after.incidents.slice(before.incidents.length)).map(e => e.kind)
    expect(fresh).toEqual(['vsc_ended', 'safety_car_deployed'])
    expect(spread(after), 'the SC compresses the field even when it replaces a VSC')
      .toBeLessThan(spread(run(1.0).after))
  })

  it('a VSC NEVER supersedes an SC', () => {
    const config = crashConfig(0.35)
    const mid = midRace(config)
    const withSc: RaceState = {
      ...mid,
      safetyCar: { deployedLap: mid.lap, lapsRemaining: 3, cause: 'crash', kind: 'sc' },
      incidents: [...mid.incidents, { lap: mid.lap, sector: 0, kind: 'safety_car_deployed', driverId: null, timeLoss: null }],
    }
    const after = stepSector(config, withSc, createRng(4))
    expect(after.cars.some(c => c.retiredCause === 'crash' && !mid.cars.find(m => m.driverId === c.driverId)!.retired),
      'premise: a car crashed this tick').toBe(true)
    expect(after.safetyCar?.kind).toBe('sc')
    expect(after.safetyCar?.deployedLap).toBe(mid.lap)
    expect(neutralisationEvents(after.incidents.slice(withSc.incidents.length))).toEqual([])
  })
})
```

```ts
/**
 * The pit-lane loss that applies right now.
 *
 * SINGLE SOURCE OF TRUTH, and that is the point. `pitLaneTimeLoss` is read at
 * five call sites (race.ts, projection.ts, raceStore.ts x2, PitTimer.tsx). If
 * a neutralisation discount were applied at some of them and not others, the
 * projection overlay would promise the player a discount the race then failed
 * to give, on the game's centrepiece decision. Every call site must route
 * through here. A VSC discounts proportionally (the field keeps racing speed
 * relationships); a full SC uses its own absolute figure.
 */
export function effectivePitLaneLoss(
  circuit: CircuitSpec,
  safetyCar: SafetyCarState | null,
  tuning: TuningConstants,
): number {
  const kind = neutralisationKind(safetyCar)
  switch (kind) {
    case null: return circuit.pitLaneTimeLoss
    case 'sc': return tuning.incidents.safetyCar.laneTimeLossUnderSc
    case 'vsc': return circuit.pitLaneTimeLoss * tuning.incidents.vsc.laneLossFactor
    default: { const never: never = kind; return never }
  }
}

/** The neutralisation in force. A state from before the VSC has no `kind`: it was a safety car. */
export function neutralisationKind(safetyCar: SafetyCarState | null): NeutralisationKind | null {
  if (safetyCar === null) return null
  return safetyCar.kind ?? 'sc'
}

/**
 * VSC deployment roll. Same guard idiom as the SC roll: a zero chance performs
 * NO rng() call, which is what keeps the golden race byte-identical with the
 * VSC switched off.
 */
export function rollVscDeployment(
  cause: 'crash' | 'mechanical',
  tuning: TuningConstants,
  rng: Rng,
): boolean {
  const v = tuning.incidents.vsc
  const chance = cause === 'crash' ? v.crashDeployChance : v.mechanicalDeployChance
  return chance > 0 && rng() < chance
}

/** Inclusive of both bounds. */
export function rollVscDuration(tuning: TuningConstants, rng: Rng): number {
  const v = tuning.incidents.vsc
  const span = v.durationLapsMax - v.durationLapsMin + 1
  return v.durationLapsMin + Math.floor(rng() * span)
}

/** Every car is scaled by the same factor, so this changes no gaps. No rng. */
export function neutralisationPaceMultiplier(safetyCar: SafetyCarState | null, tuning: TuningConstants): number {
  const kind = neutralisationKind(safetyCar)
  switch (kind) {
    case null: return 1
    case 'sc': return tuning.incidents.safetyCar.paceMultiplier
    case 'vsc': return tuning.incidents.vsc.paceMultiplier
    default: { const never: never = kind; return never }
  }
}
```

```ts
import type { NeutralisationKind, RaceConfig } from './types'
import { initRace, stepSector } from './race'
import { createRng } from './rng'
import { applyCall, type PlayerCall } from './playerCalls'
import { isFinished } from './debrief'

/**
 * The lap chart's data (spec 2026-10-16 §4): every car's position at the end of
 * every lap, its stops and its retirement, plus the SC/VSC periods.
 *
 * Built on the SAME loop as `replay` (apply the calls due at this step, stop
 * at the flag, step) so it is the race as it happened, never an approximation;
 * tests/engine/raceHistory.test.ts pins it against the live race. Runs once per
 * race, off the result screen's critical path, inside the debrief runner. It
 * adds nothing to RaceState and so cannot disturb the golden race.
 */
export interface CarHistory {
  driverId: string
  teamId: string
  isPlayer: boolean
  /** positions[0] = grid slot; positions[k] = position at the end of lap k. A retired car's array stops at the last lap it completed, so its length equals retiredLap. */
  positions: number[]
  /** 1-based lap of each stop, one entry per stop, in order. */
  pitLaps: number[]
  /** 1-based lap on which the car retired, or null. */
  retiredLap: number | null
  /** Final classified position (retired cars after every runner, as the race sorts them). */
  finish: number
}

export interface NeutralisationPeriod { kind: NeutralisationKind; startLap: number; endLap: number }

export interface LapHistory { totalLaps: number; lapsRun: number; cars: CarHistory[]; neutralisations: NeutralisationPeriod[] }

export function lapHistory(config: RaceConfig, seed: number, calls: readonly PlayerCall[]): LapHistory {
  const rng = createRng(seed)
  let state = initRace(config)
  const pending = calls.slice().sort((a, b) => a.step - b.step)
  const cars: CarHistory[] = state.cars.map(c => ({
    driverId: c.driverId, teamId: c.teamId, isPlayer: c.isPlayer,
    positions: [c.position], pitLaps: [], retiredLap: null, finish: c.position,
  }))
  const byId = new Map(cars.map(h => [h.driverId, h]))
  const pitsAtLastSample = new Map(state.cars.map(c => [c.driverId, c.pitsDone]))

  let step = 0
  let i = 0
  for (;;) {
    while (i < pending.length && pending[i]!.step === step) {
      state = applyCall(config, state, pending[i]!, rng)
      i++
    }
    if (isFinished(state)) break
    state = stepSector(config, state, rng)
    step++
    if (state.sector !== 0) continue
    // A lap just completed; state.lap is its 1-based number.
    const lap = state.lap
    for (const car of state.cars) {
      const h = byId.get(car.driverId)!
      if (h.retiredLap !== null) continue
      // Manual stops land between steps and AI/plan stops at the boundary;
      // either way they show up as pitsDone growing across this lap.
      const before = pitsAtLastSample.get(car.driverId) ?? 0
      for (let k = before; k < car.pitsDone; k++) h.pitLaps.push(lap)
      pitsAtLastSample.set(car.driverId, car.pitsDone)
      if (car.retired) {
        h.retiredLap = (car.retiredLap ?? lap - 1) + 1
        continue
      }
      h.positions.push(car.position)
    }
  }

  for (const car of state.cars) byId.get(car.driverId)!.finish = car.position

  const neutralisations: NeutralisationPeriod[] = []
  let open: { kind: NeutralisationKind; startLap: number } | null = null
  for (const ev of state.incidents) {
    if (ev.kind === 'safety_car_deployed' || ev.kind === 'vsc_deployed') {
      open = { kind: ev.kind === 'vsc_deployed' ? 'vsc' : 'sc', startLap: ev.lap + 1 }
    } else if ((ev.kind === 'safety_car_ended' || ev.kind === 'vsc_ended') && open !== null) {
      neutralisations.push({ ...open, endLap: ev.lap + 1 })
      open = null
    }
  }
  // A race can end under a neutralisation (race.ts only clears it at a boundary).
  if (open !== null) neutralisations.push({ ...open, endLap: Math.max(open.startLap, state.lap) })

  return { totalLaps: state.totalLaps, lapsRun: state.lap, cars, neutralisations }
}
```

```ts
export interface DebriefJob { config: RaceConfig; seed: number; calls: PlayerCall[] }
export interface DebriefHandle { cancel(): void }
export interface DebriefRunner {
  start(job: DebriefJob, on: {
    progress(done: number, total: number): void
    done(result: DebriefResult): void
    failed(reason: string): void
    /** The lap chart's data, delivered before judging starts so a judging timeout never costs the chart. */
    history(h: LapHistory): void
  }): DebriefHandle

/**
 * Runs the debrief on the calling thread, after a macrotask so start()
 * returns first. For tests and as a fallback; the app installs the worker
 * runner (src/state/debriefWorkerRunner.ts) at startup.
 */
export const inProcessRunner: DebriefRunner = {
  start(job, on) {
    let cancelled = false
    setTimeout(() => {
      if (cancelled) return
      try {
        const h = lapHistory(job.config, job.seed, job.calls)
        if (!cancelled) on.history(h)
      } catch { /* the chart is optional; the verdicts still run */ }
      if (cancelled) return
      try {
        let lastPct = -1
        const result = judgeCalls(job.config, job.seed, job.calls, (d, t) => {
          const pct = Math.floor((d / t) * 100)
          if (!cancelled && (pct !== lastPct || d === t)) { lastPct = pct; on.progress(d, t) }
        })
        if (!cancelled) on.done(result)
      } catch (e) {
        if (!cancelled) on.failed(String(e))
      }
    }, 0)
    return { cancel: () => { cancelled = true } }
  },
}
```

```tsx
export function highlightedDrivers(history: LapHistory, playerDriverId: string): string[] {
  const order = [...history.cars].sort((a, b) => a.finish - b.finish).map(c => c.driverId)

  const span = Math.min(HIGHLIGHTED, order.length)

export function lapChartSummary(history: LapHistory, playerDriverId: string): string {
  const car = history.cars.find(c => c.driverId === playerDriverId)
```

```ts
import type { Compound, RaceConfig, RaceState } from './types'
import { effectiveTyreAge } from './tyres'
import { PIT_CLIFF_THRESHOLD } from './strategy'

/**
 * What the pit wall can see about a rival (spec 2026-10-16 §2): observed facts
 * (compound, tyre age, stops) plus a fuzzy box window. Pure and rng-free, so
 * it cannot perturb a race, and stable within a lap: every input it reads
 * (lap, tyre age, pace mode, dirty-air laps, weather, stops) only changes at a
 * lap boundary, so the card never jitters between sectors.
 */
interface IntelBase { driverId: string; compound: Compound; tyreAge: number; stops: number }

export type RivalIntel =
  | (IntelBase & { status: 'window'; from: number; to: number })
  | (IntelBase & { status: 'flag' })
  | (IntelBase & { status: 'out' })

/**
 * A small, stable offset in [-max, +max] laps from an FNV-1a hash of the car id.
 * Keeps the window honest-but-imprecise without jittering between laps, and
 * without touching the race rng.
 */
export function intelOffset(driverId: string, maxOffsetLaps: number): number {
  let h = 2166136261
  for (let i = 0; i < driverId.length; i++) {
    h ^= driverId.charCodeAt(i)
    h = Math.imul(h, 16777619)
  }
  const span = 2 * maxOffsetLaps + 1
  return ((h >>> 0) % span) - maxOffsetLaps
}

export function rivalIntel(config: RaceConfig, state: RaceState, driverId: string): RivalIntel | null {
  const car = state.cars.find(c => c.driverId === driverId)
  if (!car) return null
  const base: IntelBase = { driverId, compound: car.compound, tyreAge: car.tyreAge, stops: car.pitsDone }
  if (car.retired) return { ...base, status: 'out' }
  // Indexed by pitsDone, exactly as strategy.ts reads the plan.
  const nextStop = car.strategy.plannedStops[car.pitsDone]
  if (!nextStop) return { ...base, status: 'flag' }

  const brain = car.strategy.brain ?? 'naive'
  const cfg = config.tuning.rivalIntel
  let centre = nextStop.lap
  const spec = config.compounds[car.compound]
  const driver = config.drivers.find(d => d.id === car.driverId)
  if (spec && driver && spec.cliff > 0) {
    // effectiveTyreAge is linear in tyreAge, so its value at age 1 is the
    // per-lap wear rate at the car's current pace mode and conditions.
    const effNow = effectiveTyreAge(car, driver, state.weatherState, config.tuning)
    const perLap = effectiveTyreAge({ ...car, tyreAge: 1 }, driver, state.weatherState, config.tuning)
    if (perLap > 0) {
      const lapsToThreshold = (PIT_CLIFF_THRESHOLD[brain] * spec.cliff - effNow) / perLap
      centre = Math.min(centre, car.lap + Math.max(0, Math.ceil(lapsToThreshold)))
    }
  }
  centre += intelOffset(driverId, cfg.maxOffsetLaps)

  const halfWidth = cfg.halfWidth[brain]
  const nowLap = state.lap + 1
  const last = state.totalLaps
  const from = Math.min(last, Math.max(nowLap, centre - halfWidth))
  const to = Math.min(last, Math.max(from, centre + halfWidth))
  return { ...base, status: 'window', from, to }
}
```

```tsx
/**
```

```ts
 * Cached, for the reason seedStride is cached in seasonStore: loadGameData()
 * re-parses every schema on every call and these are read per render and per

let cached: { rounds: number[]; distanceFraction: number; points: number[] } | null = null
function rules() {
  if (cached === null) cached = loadGameData().tuning.sprint
  return cached
}

/** raceIndex is 0-based; tuning.sprint.rounds is 1-based. */
export function isSprintRound(raceIndex: number): boolean {
  return rules().rounds.includes(raceIndex + 1)
}

export function sprintLaps(circuitLaps: number): number {
  return Math.max(1, Math.round(circuitLaps * rules().distanceFraction))
}

/** Points for a classified sprint finish; a retirement is scored 0 by the caller. */
export function sprintPointsFor(position: number): number {
  return rules().points[position - 1] ?? 0
}
```

```ts
export function seedFor(seasonNumber: number, raceIndex: number, attemptNonce: number, kind: RaceKind = 'gp'): number {
  const base = (seasonNumber - 1) * seedStride() + raceIndex * 1000 + 42 + attemptNonce * 7919
  return kind === 'sprint' ? base + sprintSalt() : base
```

```markdown
## 14. 1.5: the virtual safety car and the AI's neutralisation reaction (2026-10-16)

Spec: `docs/superpowers/specs/2026-10-16-pit-wall-1.5-features-design.md` §1. Bands: §3 rows
"VSCs / race" and "AI stops under a neutralisation / race" (measured over four n=240 cells on the
4-circuit sample; sizing rule [floor(0.7×min), ceil(1.3×max)] to 0.05).

**Trigger.** On a tick where a car newly retires, the SC is rolled first and exactly as before
(`crashDeployChance` 0.30, `mechanicalDeployChance` 0.12, tyre failures count as mechanical).
Only if it stays in is the VSC rolled (`incidents.vsc.crashDeployChance` 0.25,
`mechanicalDeployChance` 0.40). One neutralisation at a time: a VSC only opens on a green track;
an SC may supersede a running VSC (logged `vsc_ended` then `safety_car_deployed` on the same
tick, and the field IS compressed, because it is now a safety car); a VSC never supersedes an SC.
VSCs count against their own `maxPerRace` (2), so a VSC can still come out after the SC cap is
reached.

**Under a VSC.** Every car laps at `vsc.paceMultiplier` (1.30, applied in lapModel like the SC's,
so it changes no gap). Gaps are frozen: no `compressRaceTimes`. Overtakes are suspended (same
`safetyCar === null` gate as the SC). A stop costs `pitLaneTimeLoss × vsc.laneLossFactor` (0.60)
through `effectivePitLaneLoss`, the single source the projection, pit panel, pit timer and race
all read. Duration uniform 1–3 laps, ticked down per lap.

**AI reaction (SC and VSC).** Smart and optimal brains box at a lap boundary when a planned stop
remains and either it is within `ai.neutralisationWindowLaps` (6) or the tyre's cliff fraction is
at least `ai.neutralisationCliffFrac` (0.55), fitting the plan's compound on neutral pace. Naive
brains ignore it. It is a pure threshold with no rng draw. The AI decides on the neutralisation as
it stands AFTER the tick -- the same value `pitStopTime` charges -- so it never boxes on the
boundary where the SC/VSC ends and pays the green-flag loss. This is the balance call with real
feel impact (spec "Balance calls"): the cheap stop becomes a race against the smart teams.

**Invariants kept.** With both VSC chances at 0 the VSC roll draws nothing and the AI reaction
can never fire, so `tests/engine/byteIdentity.test.ts` reproduces the golden race with the fixture
unchanged (`makeDeterministicTuning` zeroes the VSC chances alongside the SC's). `SafetyCarState.kind`
is optional and read through `neutralisationKind` (absent = SC), so no older state changes meaning.

**Also pure, also outside RaceState.** `lapHistory` (`src/engine/raceHistory.ts`) replays
(config, seed, calls) on the replay loop and samples every lap end; `rivalIntel`
(`src/engine/rivalIntel.ts`) projects a rival's stop from the same per-brain thresholds
strategy.ts acts on (`PIT_CLIFF_THRESHOLD`), with a ±1 lap offset from a hash of the car id
rather than the rng. Neither can perturb a race.

**Sprints.** `RaceConfig.lapsOverride` (absent = circuit laps) and `mandatoryTwoCompound: false`;
sprint AI strategies carry no planned stops. The Monte-Carlo bands are Grand Prix bands and were
not re-measured on sprint distance.
```
